# 1.1.0 TMDb監査ランタイム識別

## 背景

2026-09-16の実機監査では、新しい日時の監査CSVが生成されているにもかかわらず、matcher v3で追加したタイトル正規化やmovie/tv文脈判定が反映されていないことが判明した。

監査CSVには従来、アプリ表示バージョンや内部matcher versionが記録されていなかったため、実機で旧プロセス／旧バイナリが動いた場合にファイル単体では識別できなかった。

## 修正

- 内部matcher versionを4へ更新する。
- DB内のmatcher versionが4未満なら、既存MATCHEDも一度だけ再評価する。
- 監査JSON summaryへ `appVersion` と `matcherVersion` を記録する。
- 監査JSON itemsの各行へ同じ2項目を記録する。
- 監査CSVの各行へ `appVersion` と `matcherVersion` を記録する。
- 表示上のアプリバージョンは `1.1.0` のまま維持する。
- matcher v3で追加したタイトルvariant正規化、movie/tv文脈判定、複数年movieの自動MATCHED抑止はそのまま維持する。

## 実機確認

更新版を完全終了状態から上書きインストールし、`TMDb同期` を実行する。

新しいCSVの先頭列で以下を確認する。

- `appVersion = 1.1.0`
- `matcherVersion = 4`

その後、440作品についてMATCHED / REVIEW / UNMATCHEDを再監査する。特に `TRICK`、`プライド`、`VIVANT`、`YASHA-夜叉-`、`Q10`、`HiGH&LOW`、`ミス・シャーロック/Miss Sherlock`、`男はつらいよ` を優先確認する。
