# 自宅動画ライブラリ v1.0 画面設計

## 主要画面
- ホーム
- ライブラリ
- 検索
- 作品詳細
- 動画再生
- お気に入り
- 視聴履歴
- 設定 / 利用者
- 管理・診断

## ホーム優先順位
1. 続きから見る
2. 次に見る
3. 最近見た作品
4. お気に入り
5. ライブラリ
6. 最近追加

該当0件のセクションは非表示にする。

## ライブラリ
カード / 一覧を切替可能とし、分類、未視聴、途中、視聴済み、お気に入りで絞り込む。正式日本語タイトルを基本に50音・英字索引を持つ。

## 作品詳細
映画は単独再生を中心に表示。TV/アニメは `series_groups` 単位でエピソードを表示する。OVA/OAD/特典/ファン編集等を本編と区別する。

## 再生
HTML5 `<video>` を基本とし、v1.0ではブラウザ標準コントロールを利用する。再生位置を保存し「続きから再生」を提供する。

## モバイル
スマートフォンは1カラム、下部ナビゲーション、44px前後のタップ領域、iPhone safe areaを考慮する。
