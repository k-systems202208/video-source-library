# 関町北映画館 v1.1.0 画面設計

## 全体

Web UIはレトロ映画館をモチーフにし、PC / Tablet / Smartphoneで同じ情報構造とハッシュルートを使用する。

PCでは左側の館内メニューを主ナビゲーションとし、画面幅に応じてレスポンシブ表示する。

## 主なルート

- `#/home/continue`: 上映中
- `#/home/next`: 次回上映
- `#/library`: 作品目録
- `#/people/directors`: 監督／演出
- `#/people/cast`: 主な出演者／声優
- `#/person/<name>`: 人物別作品一覧
- `#/work/<id>`: 作品詳細

## ホーム / 作品目録

- 上映中: 続きから見られる動画
- 次回上映: 次に見る候補
- 作品目録: 全作品
- 検索、カテゴリ、並び替え、ページング
- posterがある作品は画像を表示し、画像なしはタイトルフォールバック
- TMDb画像取得に失敗しても作品情報自体は表示する

## 作品詳細

- poster
- backdrop
- カテゴリ / 作品名
- 視聴進捗
- お気に入り
- TMDb overview
- 監督／演出
- 主な出演者／声優
- series group
- エピソード / 上映目録

人物名はクリック可能とし、人物別作品一覧へ遷移する。

画像と作品情報は同じ `tmdb_work_links` の現在のMATCHED作品を基準とする。

## 人物名鑑

### 監督／演出

- ローカル `director_or_direction` から人物名と登録作品数を表示
- テキストカード
- 顔写真は表示しない

### 主な出演者／声優

- ローカル `main_cast_or_voice_actors` を人物名鑑の正本とする
- 安全にTMDb人物IDが確定した人物は顔写真カード
- `profile_path` がない、または人物ID未確定の場合は `PROFILE NOT AVAILABLE`
- 写真の有無に関係なく人物カードから登録作品へ遷移可能

## 動画再生

動画はプレイヤーモーダルで再生する。

- ブラウザ直接再生できる場合は元動画をRange配信
- 非互換の場合はFFmpegで互換MP4を準備
- 変換中は準備状況を表示
- 外部字幕はWebVTTとして配信
- 再生位置を保存して続きから再生
- 視聴済み・お気に入りを更新可能

## 診断

Owner専用診断画面はメイン画面から開く。

- MISSING / NEW_FILE
- 未紐付字幕
- 対応動画なし字幕
- 未対応字幕
- scan error
- 安全な修復候補
- JSON / CSV出力

診断は読み取り専用で元ファイルやDB紐付けを自動変更しない。

## 画像フォールバック

- 作品poster/backdrop: 現在のTMDb image pathに対応するローカルキャッシュのみ利用
- 出演者／声優の人物画像: `/tmdb-person-image/{id}`
- 監督／演出: 画像なし
- 画像読み込み失敗はUI全体の失敗にしない

## PWA / オフライン

PWAとしてインストール可能。ナビゲーション時にサーバーへ接続できない場合だけオフライン画面を表示し、動画/API/字幕/TMDb画像はService Workerへキャッシュしない。
