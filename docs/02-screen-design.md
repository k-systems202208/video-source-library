# 関町北映画館 v1.3.0 画面設計

## 全体

Web UIはレトロ映画館をモチーフにし、PC / Tablet / Smartphoneで同じ情報構造とハッシュルートを使用する。

PCでは左側の館内メニューを主ナビゲーションとし、画面幅に応じてレスポンシブ表示する。

## 主なルート

- `#/home/continue`: 上映中
- `#/home/next`: 次回上映
- `#/library`: 作品目録
- `#/people/directors`: 監督／演出
- `#/people/cast`: 主な出演者／声優
- `#/person/<name>`: 人物別作品一覧
- `#/work/<id>`: 作品詳細

## ホーム / 作品目録

- 上映中: 続きから見られる動画
- 次回上映: 次に見る候補
- 作品目録: 全作品
- 検索、カテゴリ、並び替え、ページング
- posterがある作品は画像を表示し、画像なしはタイトルフォールバック
- TMDb画像取得に失敗しても作品情報自体は表示する
- 通常の作品目録は、現在の利用者について有効visibilityが1の作品だけを表示する。Tailscale利用者は個別設定を優先し、個別値がない作品は共通設定を継承する

## 作品詳細

- poster
- backdrop
- カテゴリ / 作品名
- 視聴進捗
- お気に入り
- TMDb overview
- 監督／演出
- 主な出演者／声優
- series group
- エピソード / 上映目録

人物名はクリック可能とし、人物別作品一覧へ遷移する。

画像と作品情報は同じ `tmdb_work_links` の現在のMATCHED作品を基準とする。

ブラウザ画面には作品表示設定の操作UIを置かない。表示対象はWindowsランチャーで設定する。

## Windowsランチャーの表示設定

- 「表示設定」ボタンから登録済み全作品を開く
- 「対象ユーザー」で `共通設定` またはアクセス済みTailscaleユーザーを選択
- 初回アクセス前のTailscaleユーザーはDBに未登録のため、アクセス後にダイアログを開き直すと選択可能
- 共通設定は `works.is_visible`、Tailscaleユーザー個別設定は `user_work_visibility` を編集
- 個別設定未作成時は「共通設定を継承」と表示
- 「共通設定に戻す」でそのユーザーの個別設定を削除
- 各作品をチェックボックスで選択
- 「すべて選択 / すべて解除」チェックボックスで全件を一括切替
- 「作品名フィルター」で部分一致絞り込み。入力中もチェック状態を保持
- 「クリア」で全作品表示へ戻し、「表示 n / 全m作品」で絞り込み件数を確認
- 保存時にチェックされた作品だけを対象設定で表示する。共通設定では `works.is_visible`、Tailscaleユーザーでは当該ユーザーの `user_work_visibility` を更新する
- 非表示作品はその利用者について、作品目録、上映中、次回上映、人物名鑑、お気に入り、履歴、直接URL、動画配信、字幕、TMDb画像から除外

## 人物名鑑

### 監督／演出

- ローカル `director_or_direction` から人物名と登録作品数を表示
- テキストカード
- 顔写真は表示しない

### 主な出演者／声優

- ローカル `main_cast_or_voice_actors` を人物名鑑の正本とする
- 安全にTMDb人物IDが確定した人物は顔写真カード
- `profile_path` がない、または人物ID未確定の場合は `PROFILE NOT AVAILABLE`
- 写真の有無に関係なく人物カードから登録作品へ遷移可能

## 動画再生

動画はプレイヤーモーダルで再生する。

- ブラウザ直接再生できる場合は元動画をRange配信
- 非互換の場合はFFmpegで互換MP4を準備
- 変換中は準備状況を表示
- 外部字幕はWebVTTとして配信
- 再生位置を保存して続きから再生
- 視聴済み・お気に入りを更新可能

## 診断

Owner専用診断画面はメイン画面から開く。

- MISSING / NEW_FILE
- 未紐付字幕
- 対応動画なし字幕
- 未対応字幕
- scan error
- 安全な修復候補
- JSON / CSV出力

診断は読み取り専用で元ファイルやDB紐付けを自動変更しない。

## 画像フォールバック

- 作品poster/backdrop: 現在のTMDb image pathに対応するローカルキャッシュのみ利用
- 出演者／声優の人物画像: `/tmdb-person-image/{id}`
- 監督／演出: 画像なし
- 画像読み込み失敗はUI全体の失敗にしない

## PWA / オフライン

PWAとしてインストール可能。ナビゲーション時にサーバーへ接続できない場合だけオフライン画面を表示し、動画/API/字幕/TMDb画像はService Workerへキャッシュしない。
