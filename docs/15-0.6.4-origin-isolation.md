# 0.6.4 localhost origin分離

## 背景
自宅音楽ライブラリと自宅動画ライブラリが同じ `127.0.0.1:8765` を使用していたため、Service Worker / Cache Storage / PWA shellが同一originに属し、音楽版の `offline.html` が動画版のowner bootstrap画面として返る実機不具合が発生した。

## 対応
- 音楽版: `127.0.0.1:8765` を維持
- 動画版: `127.0.0.1:8876` へ変更
- 動画版Windowsアプリを0.6.4へ更新
- owner bootstrap fragment方式は0.6.3のまま維持

ポートはoriginの一部であるため、これによりService Worker、Cache Storage、PWA manifestなどのブラウザ状態が両アプリ間で共有されなくなる。

## データへの影響
`%LOCALAPPDATA%\VideoLibrary` の `library.db`、`config.json`、`metadata/video_library.json`、バックアップは変更しないため、アップグレード後の再取込は不要。
