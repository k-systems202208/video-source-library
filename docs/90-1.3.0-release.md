# 自宅動画ライブラリ 1.3.0

## 概要

1.3.0では、Windowsランチャーの作品表示設定をTailscale利用者ごとに設定できるようにした。

従来の共通表示設定はそのまま残り、個別設定を作成していない利用者は共通設定を継承する。

## 追加

- 表示設定の `対象ユーザー`
- 共通設定 + アクセス済みTailscaleユーザーの切替
- Tailscaleユーザーごとの表示／非表示
- `個別設定 / 共通設定を継承` 状態表示
- `共通設定に戻す`
- 未保存変更があるユーザー切替時の破棄確認

## DB

SQLite schemaを8から9へ更新した。

追加:

- `user_work_visibility`

既存 `works.is_visible` は共通設定として残す。

個別行がない場合は共通設定へフォールバックするため、1.2.3から上書き更新しただけでは既存ユーザーの表示結果は変わらない。

## Tailscale

既存のTailscale Serve identityから解決した `user_id` をそのまま表示設定に使用する。

ユーザーはTailscale経由で初回アクセスした時点でDBへ登録され、その後Windowsランチャーの対象ユーザー一覧に現れる。

新しいログイン方式やユーザー登録画面は追加しない。

## visibility適用範囲

ユーザー別visibilityは次へ一貫して適用する。

- 作品一覧 / 検索 / 詳細
- 動画一覧 / 詳細 / 配信
- 字幕
- TMDb作品画像 / 人物画像
- 人物名鑑
- お気に入り
- 続きから見る / 次に見る
- 最近見た作品 / 履歴
- ライブラリ件数

非表示作品は対象ユーザーから直接URLを指定しても404を返す。

## 継続仕様

## 更新方法

1.2.3へ上書きインストール可能。

schema migrationは追加テーブル作成のみで、既存の共通表示設定・利用者状態・TMDb情報を保持する。
