# 1.2.1 Windowsランチャー表示設定

## 目的

作品の表示対象をブラウザではなくWindowsランチャーだけで管理する。

ブラウザは「選択された作品を閲覧・再生する場所」とし、何を表示するかの設定UIや管理APIを持たない。

## Windowsランチャー

ランチャーに `表示設定` ボタンを追加する。

押下するとSQLiteに登録されている全作品を読み込み、スクロール可能なチェックリストとして表示する。

各行:

- 作品番号
- カテゴリ
- 作品名
- 年／期間
- 表示対象チェックボックス

現在 `works.is_visible=1` の作品はチェック済み、`0` は未チェックで開く。

### 一括選択

上部に `すべて選択 / すべて解除` チェックボックスを設置する。

- ON: 全作品をチェック
- OFF: 全作品のチェックを解除

選択数を `選択 n / 全m作品` で表示する。

### 保存

保存時は現在のチェック状態を1トランザクションで全置換する。

1. 全作品を `is_visible=0`
2. チェックされた作品だけ `is_visible=1`
3. commit

0件選択も許可する。

サーバー起動中に変更した場合、ブラウザ再読み込み後に反映する。

## ブラウザ

1.2.0で追加した次のUIを撤回する。

- 表示設定ボタン
- 表示中 / 非表示 / すべて切替
- カード上のチェックボックス
- 一括表示 / 非表示
- 作品詳細の表示切替ボタン

また、次の管理APIも撤回する。

- `GET /api/works?visibility=hidden|all` による非表示作品取得
- `PUT /api/admin/works/visibility`

`GET /api/works` は常に `is_visible=1` の作品だけを返す。

## 非表示作品へのアクセス

`is_visible=0` の作品はブラウザから取得できない。

対象:

- 作品一覧
- 作品詳細
- 作品内動画一覧
- 動画詳細
- 動画配信
- 外部字幕配信
- TMDb作品画像
- 上映中 / 次回上映
- お気に入り
- 視聴履歴
- 人物名鑑 / 人物検索

直接URLを知っていても404とする。

## DB

schema 8を継続利用する。

```sql
works.is_visible INTEGER NOT NULL DEFAULT 1
```

metadata再取込では `is_visible` を上書きしない。

## テスト

- ランチャー用全作品一覧取得
- 選択IDだけvisibleになる全置換
- 0件選択 / 全件選択
- metadata再取込で選択状態保持
- ブラウザに表示設定UIが存在しない
- ブラウザvisibility管理APIが存在しない
- hidden作品の作品詳細 / 動画詳細 / 動画配信が404
- 通常の人物名鑑・履歴・お気に入り等からhidden除外
