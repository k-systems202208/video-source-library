# 1.1.0 TMDb画像キャッシュ更新

## 背景

TRICKは過去のmatcherで同名映画へ誤MATCHEDされた時期があり、その後TMDb TV `19616`へ照合を修正した。
ただし画像キャッシュは `workId + 拡張子` で保存し、既存ファイルがあれば再取得しないため、古い別作品のポスターが残るケースがあった。

## 対応

- MATCHEDのTMDb種別・ID・poster_path・backdrop_pathが変化した場合は対応画像を強制再取得する。
- REVIEW/UNMATCHEDからMATCHEDへ変化した場合も、過去の孤立キャッシュを再利用せず取り直す。
- 強制更新時は旧キャッシュを削除してからダウンロードする。失敗した場合に誤画像を表示し続けない。
- 既存インストールのTRICK (`2000-2003`) は一度だけポスター／背景を強制更新する。
- matcherの判定ロジックと表示バージョン `1.1.0` は変更しない。

## 回帰テスト

`tests/test_tmdb_image_cache_refresh_v110.py` で、照合先変更時の更新判定・変更なし時の非更新・既存画像の強制置換を確認する。
