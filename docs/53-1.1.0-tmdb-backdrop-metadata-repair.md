# 1.1.0 TRICK 背景メタデータ修復

## 背景

Run #167でTRICKの旧画像キャッシュを強制再取得した結果、ポスターは正常化したが背景だけ別作品のまま残った。
原因は、既にMATCHEDの作品ではTMDb詳細を再取得せず、DBに保存済みの `backdrop_path` をそのまま利用していたため。
古い `backdrop_path` の画像を再ダウンロードしても、正しい背景にはならない。

## 対応

- `TmdbClient.movie_details()` / `tv_details()` を追加。
- 画像修復バージョンを2へ更新。
- 既存TRICK (`2000-2003`, `tv/19616`) に限り、次回TMDb同期時に1回だけ作品詳細を再取得する。
- 正しいTMDb IDは維持したまま `poster_path` / `backdrop_path` / `overview` 等をDBへ再保存する。
- 更新された画像パスを使ってポスター・背景キャッシュを強制再取得する。
- matcher v7および表示バージョン1.1.0は維持する。
- 通常の既存MATCHED作品を毎回詳細APIへ問い合わせない。

## テスト

`tests/test_tmdb_detail_metadata_refresh_v110.py` で詳細APIのURL、TRICKのstale backdrop置換、ID不一致拒否、修復バージョン2を検証する。
