# 0.9.3 全件再生監査ボタンのランチャー配置修正

## 背景

0.9.2では全件再生監査機能をWindowsランチャーへ追加したが、標準サイズ `780x690` では起動スキャン欄の要求高さにより、最下部のフッターが画面外へ押し出される場合があった。

## 修正

- `バックアップ作成`、`全件再生監査`、`状態再確認` を起動スキャン欄より前に配置する
- 起動スキャン欄だけを `expand=True` の可変領域として残す
- 標準ウィンドウサイズ `780x690` は変更しない
- スキャンログの初期高さを8行から4行へ縮小し、標準サイズで主要操作と進捗を両立する
- 0.9.2の監査処理、JSON/CSV形式、`NO_ROUTE = 0` の受入条件は変更しない

## 回帰テスト

`tests/test_launcher_layout_v093.py` で以下を固定する。

- 監査操作エリアが起動スキャン欄より先に生成される
- `全件再生監査` ボタンが起動スキャン欄より先に存在する
- 起動スキャン欄のみが `expand=True` である
- 旧フッター配置へ戻っていない
- `780x690` とコンパクトなログ高さを維持する

## 実機確認

0.9.3を上書きインストールし、標準サイズのまま `全件再生監査` が表示されることを確認する。その後、ライブラリ停止中に全件再生監査を実行して4,869件 / `NO_ROUTE = 0` を確認する。
