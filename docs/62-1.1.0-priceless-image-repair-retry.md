# 1.1.0 PRICELESS画像修復の再実行

## 実機確認結果

前回の画像キャッシュ修復後、次の4作品のうち3作品は正しい画像へ更新された。

- スマイル (2009)
- ビギナーズ! / ビギナーズ！ (2012)
- プライド (2004)

一方、`PRICELESS〜あるわけねぇだろ、んなもん!〜` (2012) だけ過去の誤画像が残った。

最新のTMDb監査では PRICELESS は `tv / 70203 / 2012` の正しい作品へ `MATCHED` 済みであり、作品同定ではなく workId 名で残った画像キャッシュの再修復が必要な状態だった。

## 原因

画像修復は `tmdb:image-cache-repair-version` を使った一度だけの移行処理である。

一度 v3 の修復済みマーカーが保存されると、同じ対象作品に誤画像が残っていても次回以降のTMDb同期では修復処理が再実行されない。そのため PRICELESS だけを実機で再確認した時点では、既存MATCHEDと画像キャッシュがそのまま再利用されていた。

## 対応

- `tmdb_sync.py` 側の公開キャッシュキーと matcherVersion 7 は変更しない。
- `tmdb_cache.py` で画像修復マーカーの物理保存キーだけを `gen2` へ切り替える。
- 旧v3マーカーを持つ既存環境では、既存の `_STALE_IMAGE_REPAIR_WORKS` だけが1回再実行される。
- 再実行後は `gen2` 側へ修復済みマーカーを保存するため、毎回画像を再取得することはない。
- PRICELESS の回帰テストでは既存リンク `tv / 70203` を保持したまま、poster/backdrop の両方が置換され、2回目の同期では再修復されないことを確認する。

## 実機確認手順

1. 最新版を上書きインストールする。
2. ランチャーから「TMDb同期」を1回実行する。
3. `PRICELESS〜あるわけねぇだろ、んなもん!〜` の一覧ポスターと詳細背景を確認する。
4. 正しい画像は、木村拓哉がピンク色のTシャツを着て中央にいる2012年フジテレビ版のビジュアルである。

バージョン表示は引き続き `1.1.0` とする。
