# 1.2.2 Windowsランチャー表示設定フィルター

## 目的

Windowsランチャーの「作品の表示設定」で、約440作品から対象作品を素早く探せるようにする。

## UI

表示設定ダイアログ上部に次を追加する。

- `作品名フィルター` テキストボックス
- `クリア` ボタン
- `表示 n / 全m作品` 件数表示

フィルター入力時は入力のたびに即時反映する。

## 照合ルール

- 作品名に対する部分一致
- 大文字小文字を区別しない
- 前後空白を無視
- Unicode NFKCで正規化する

例:

- `男` → `電車男`、`男はつらいよ`
- `train` → `Train Man`
- `ＴＲＡＩＮ` → `Train Man`

## 選択状態

フィルターは行の表示だけを変える。

- チェック状態は `work_id` ごとの `BooleanVar` に保持
- フィルターで一時的に非表示になった作品のチェック状態は変更しない
- フィルターを解除すると元の順序で全作品を再表示
- 保存時はフィルター状態ではなく全作品の現在チェック状態を保存する

## 一括選択

既存の `すべて選択 / すべて解除` は仕様を変えない。

フィルター中でも全作品を対象にする。

## DB / Browser

変更なし。

- SQLite schema 8
- `works.is_visible`
- ブラウザ側に表示設定UI/APIは持たない
- 非表示作品は従来どおりブラウザから取得不可

## テスト

- 日本語部分一致
- 英字の大文字小文字無視
- NFKC正規化
- 前後空白無視
- 空文字で全件
- 該当なし
- フィルター処理でvisibility値を変更しない
- ランチャーにフィルター欄・クリア・件数表示・live filteringが存在
