# 1.1.0 サイト名初期化と人物フィルター解除

## 対応内容

- 左サイドバーとヘッダーの「シネマ蔵書館」をボタン化し、クリック時にURLハッシュを除去してからページを再読み込みする。
- これにより作品詳細や人物名鑑など、どの画面からでも初期状態へ戻れる。
- 人物別作品フィルターを解除する共通処理を追加。
- 上映中・次回上映・作品目録へ戻る際は作品一覧を必ず再取得し、検索欄だけ空で古い人物フィルター結果が残る状態を防止する。
- 人物名鑑へ移動する際も直前の人物検索状態を解除する。

## 維持する仕様

- 表示バージョン 1.1.0
- PC / タブレット / スマートフォンのレスポンシブUI
- 通常検索、カテゴリ、並び順、再生、TMDb、人物リンク、お気に入り
