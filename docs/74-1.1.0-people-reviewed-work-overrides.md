# 1.1.0 出演者顔写真 第7照合（監査済み作品人物）

## 実機監査結果

`tmdb-people-audit-20260918-161017.csv` では997人を監査し、第6照合後に次の結果となった。

- PROFILE_READY: 961（前回938から+23）
- PERSON_NO_PROFILE: 9（前回7から+2）
- PERSON_SEARCH_NOT_IN_CREDITS: 10
- CREDIT_PERSON_NOT_FOUND: 1（前回26から-25）
- NO_MATCHED_WORK: 16

第6照合は監査対象26人中25人の人物を特定できた。残りは人物名の表記だけではなく、TMDb作品creditsの不足や作品自体の誤照合が中心になっている。

## 第7照合

TMDb作品creditsに人物が収録されていなくても、実機監査と作品側の一次・公式情報で出演関係を確認し、TMDb person IDまで確認できたものだけを固定overrideとして扱う。

`tmdb_people_reviewed_overrides.py` に `(media_type, tmdb_id, local_name) -> tmdb_person_id` を保持する。

対象:

- 東京湾景 / 石坂浩二 → 107961
- ラブシャッフル / DAIGO → 1111225
- 99年の愛〜JAPANESE AMERICANS〜 / 大泉洋 → 40450
- 青空の卵 / 春川恭亮 → 2661404
- HiGH&LOW〜THE STORY OF S.W.O.R.D.〜 / TAKAHIRO → 1448214
- アカギ / 郭智博 → 20345
- ブスの瞳に恋してる2019 / EXILE NAOTO → 2201144

安全条件:

1. 第1〜6照合で未確定の場合のみ第7照合を使用する。
2. `media_type`、TMDb作品ID、ローカル人物名の3つが完全一致した場合だけoverrideを参照する。
3. `/person/{id}` の人物詳細を取得し、返却されたperson IDがoverrideのIDと一致することを必須とする。
4. ID不一致、詳細取得不可の場合は未照合のまま残す。
5. fuzzy matching、部分一致、類似度判定には使用しない。

## 千紗 / CHISA

`歌のおにいさん` のTMDb creditsには `CHISA` として存在するため、第6照合の監査済みcredits別名に `千紗 → CHISA` を追加する。

## 「半分の月がのぼる空」誤照合修復

ローカルの2006年作品はテレビ東京の実写ドラマだが、既存の監査承認でTMDb `tv:34746` のアニメへMATCHEDされていた。

対策:

- `_AUDIT_APPROVED_MATCHES` から `半分の月がのぼる空 / 2006 → tv:34746` を削除。
- `_AUDIT_SPECIAL_UNMATCHED` に同作品を追加し、今後はこの候補へ自動MATCHEDしない。
- matcher versionを7から8へ更新。
- 既存MATCHEDを保持する通常ルールの例外 `_AUDIT_FORCE_REASSESS_WORKS` に登録。
- 人物同期version 7の初回バックグラウンド処理でも、既存の `tv:34746` リンクをUNMATCHEDへ自動修復し、誤った人物リンクを削除する。

これにより、ユーザーが手動TMDb同期を実行しなくてもアップデート後の通常起動で誤リンクを修復できる。
