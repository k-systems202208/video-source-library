# 0.7.0 スキャン診断

## 目的

実機スキャンで検出された `MISSING` / `NEW_FILE` / 未紐付字幕 / scan error を、ファイルを変更せずに確認・分析するためのOwner専用診断機能です。

0.6.9実機確認では、440作品 / 4,869動画に対して `MATCHED 4,828 / MISSING 41 / NEW_FILE 41`、字幕1,234件のうち未紐付880件が確認されました。欠落と新規が同数であるため、改名・移動・表記差の可能性を安全に確認することを優先します。

## 原則

- 診断は読み取り専用
- 元動画・字幕を移動、改名、削除しない
- `video_files.relative_path` を自動更新しない
- `subtitles.video_id` を自動更新しない
- 候補スコアだけで自動修正しない
- APIへ返すのは動画ルートからの相対パスのみ
- 診断APIはOwner専用

## 画面

`/diagnostics.html`

表示内容:

- 最新SUCCESSスキャンの概要
- MISSING一覧
- NEW_FILE一覧
- 未紐付字幕一覧
- scan error / ffprobe error一覧
- MISSING→NEW_FILE候補
- 字幕→動画候補
- JSON / CSVエクスポート

メインライブラリ画面の右上に「診断」導線を追加します。

## API

```text
GET /api/admin/scan-diagnostics
GET /api/admin/scan-diagnostics.json
GET /api/admin/scan-diagnostics.csv
```

オプション:

```text
?runId=<scan_run_id>
```

未指定時は最新のSUCCESSスキャンを使用します。

## MISSING / NEW_FILE候補判定

候補判定は次を点数化します。

- ファイルサイズ完全一致
- ファイルサイズ近似
- 拡張子一致
- ファイル名stem完全一致
- ファイル名stem類似
- 親フォルダー一致・類似

信頼度:

```text
HIGH   score >= 90
MEDIUM score >= 70
LOW    score < 70
```

表示対象は最低スコア45以上、上位3候補です。

HIGHであっても自動更新はしません。

## 未紐付字幕候補判定

既存の本番自動紐付けは従来どおり安全側を維持します。

診断では、未紐付字幕に対して次を参考に候補を提示します。

- 同一フォルダー
- 近似フォルダー
- stem完全一致
- 動画stemをprefixに持つ字幕名
- stem類似度

例:

```text
Movie.mkv
Movie.commentary.srt
```

本番自動紐付けでは `commentary` の意味を推測しないためUNMATCHEDですが、診断画面では `Movie.mkv` を候補として提示できます。

## エクスポート

### JSON

画面と同じ階層構造をUTF-8 JSONで出力します。

### CSV

Excelで直接開きやすいようUTF-8 BOM付きで出力します。

列:

```text
section,path,candidate_path,score,confidence,reasons,details
```

section例:

- `MISSING`
- `MISSING_CANDIDATE`
- `NEW_FILE`
- `UNMATCHED_SUBTITLE`
- `SUBTITLE_CANDIDATE`
- `ERROR`

## セキュリティ

- 診断HTML自体には個人データを埋め込まない
- 診断データAPIはOwner Cookie必須
- Tailscale一般利用者は403
- 匿名利用は401
- 絶対パス、動画ルート、Windowsドライブ文字をAPIへ付加しない

## テスト

- MISSING / NEW_FILE同一候補のスコアリング
- 未紐付字幕候補
- 診断実行でDBが変更されないこと
- JSON / CSVエクスポート
- Ownerのみ診断APIへアクセス可能
- Tailscale一般利用者は403
- メイン画面から診断画面への導線
- PyInstallerへ `diagnostics.html` が同梱されること

## 今後

実機診断結果を確認した後、候補の傾向に応じて以下を別Issueで検討します。

- 改名・移動ファイルの安全な再紐付け
- 字幕命名ルールの拡張
- 手動確定UI

0.7.0では候補提示までとし、自動修正は行いません。
