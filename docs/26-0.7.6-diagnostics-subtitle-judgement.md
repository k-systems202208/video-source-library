# 0.7.6 診断ヘッダーの字幕判定表示を明確化

## 背景

0.7.5 の実機確認では、対応字幕 1,234 件のうち 1,227 件が動画へ紐付き、残り 7 件は「対応動画なし」として正常系へ分離できた。

従来の診断ヘッダーは `字幕 1227/1234` と表示していたため、7件が未解決に見える余地があった。

## 変更内容

診断画面上部を次の形式へ変更する。

```text
動画 4869/4869・字幕判定 1234/1234（紐付 1227・対応動画なし 7）
```

字幕判定済み件数は次の式で表示する。

```text
subtitlesMatched + orphanSubtitles
```

総数は従来どおり `subtitlesFound` を使用する。

## 変更しないもの

- 字幕マッチング処理
- `subtitles.video_id` の更新ロジック
- 対応動画なし判定ロジック
- MISSING / NEW_FILE / 未対応字幕 / エラーの分類
- 元の動画・字幕ファイル

したがって 0.7.6 は診断表示のみの改善である。

## 実機期待値

0.7.5 で確認済みのライブラリでは次の表示を期待する。

- 動画: 4,869 / 4,869
- 字幕判定: 1,234 / 1,234
  - 紐付: 1,227
  - 対応動画なし: 7
- 未紐付字幕: 0
- 未対応字幕: 3
- エラー: 0

## テスト

`tests/test_diagnostics_ui_v076.py` で以下を固定する。

- 判定済み字幕が `subtitlesMatched + orphanSubtitles` であること
- ヘッダーに「字幕判定」「紐付」「対応動画なし」を表示すること
- 旧 `字幕 matched/found` 表示へ戻らないこと
- Windows版とインストーラーのバージョンが 0.7.6 で一致すること
