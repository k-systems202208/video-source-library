# 0.7.2 安全な字幕一意照合

## 背景

0.7.1の実機スキャンでは動画4,869件がすべて一致した一方、HTML字幕対象 `.srt` / `.vtt` / `.ass` / `.ssa` は1,234件中354件のみ紐付済みで、880件が未紐付だった。

診断JSONと元ファイル一覧を確認すると、未紐付の主因は次の通りだった。

- `Subs` / `Subtitles` / `SubsExtracted` 等のサブフォルダーに字幕だけ格納されている
- 動画と字幕でrelease名や言語suffixが異なる
- `S02E10` / `2x10` / `S4_10` / `ep501` / `E10` 等、同じ話数を異なる形式で表記している
- 映画など、作品内の動画が1本だけなのに字幕名が動画名と一致しない

従来の同一フォルダー＋同一stemだけではこれらを安全に処理できなかった。

## 基本方針

自動紐付けは「同じ作品の中で候補が1件に一意に決まる場合」だけ行う。類似度だけで候補を選ばない。

元動画・字幕ファイルは変更、移動、改名しない。更新するのはSQLite `subtitles.video_id` と付随するmatch_method等のみ。

## 判定順序

1. `EXACT_STEM`
   - 従来どおり、同一フォルダーで動画と字幕のstemが一致

2. `LANGUAGE_SUFFIX`
   - 従来どおり、同一フォルダーで `.ja` / `.jpn` / `.forced` / `.default` 等の既知suffixだけが追加されている

3. `WORK_EXACT_STEM`
   - 同一作品ルート内でstem完全一致の動画が1件だけ
   - `Show/Subtitles/Episode 01.ass` → `Show/Episode 01.mkv` 等

4. `WORK_STEM_PREFIX`
   - 字幕stemが動画stem全体をprefixとして持ち、境界が `.`, space, `_`, `-`, `[`, `(` 等で明確
   - 候補が同一作品内で1件だけ

5. `WORK_SINGLE_VIDEO`
   - 同一作品内の登録動画が1本だけ
   - 複数字幕を同じ映画へ紐付けることは許容

6. `EPISODE_NUMBER`
   - 次の表記を正規化して話数を比較する
     - `S02E10`
     - `2x10`
     - `S4_10`
     - `ep501` → Season 5 Episode 01
     - `E10` / `EP10`
     - `第10話`
   - 同一作品内で話数候補が1件だけの場合のみ採用
   - 字幕ファイル名に明示された話数をフォルダー名より優先する

## 自動紐付けしないケース

- 同一ルールで複数動画が候補になる
- Seasonが明示されて衝突する
- `movie.commentary.srt` のような意味解釈を必要とする別トラック
- 作品ルートが異なる動画

`commentary` は従来仕様を維持し、作品内に動画が1本でも自動紐付けしない。

## 字幕総数1,237件との差

元一覧の字幕1,237件のうち、HTML字幕として現在扱う `.srt` / `.vtt` / `.ass` / `.ssa` は1,234件。

残り3件は次の未対応形式。

- `.idx` 1件
- `.sub` 1件
- `.smi` 1件

IDX/SUBは画像字幕の組であり、通常のWebVTT系字幕と同一処理にはしない。SMIも現時点では未対応。これらはHTML字幕1,234件へ無理に混ぜない。

## テスト

- 従来のEXACT_STEM / LANGUAGE_SUFFIX
- `Subtitles`配下のstem完全一致
- 一意prefix
- 作品内動画1本
- `SxxExx` / `x` / `Sx_nn` / `ep501` / `E10`
- 誤配置された字幕でファイル名側話数を優先
- 同一Episode番号が複数Seasonにある場合の曖昧判定
- commentaryを自動紐付けしない
- `.idx` / `.sub` / `.smi` をHTML字幕対象に含めない

CIではPython 3.11 / 3.13の全テストと440作品 / 4,869動画の合成fixtureを維持する。
