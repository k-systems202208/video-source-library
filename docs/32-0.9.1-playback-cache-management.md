# 0.9.1 PlaybackCache 容量管理

## 背景

0.9.0で、ブラウザが直接再生できない動画を初回再生時にH.264 + AAC MP4へ変換し、`%LOCALAPPDATA%\VideoLibrary\PlaybackCache` に保存する互換再生を実装した。

長期利用では変換済みMP4が増え続けるため、0.9.1で容量管理を追加する。

## 仕様

- 標準上限は20GiB。
- Windowsランチャーに現在容量、ファイル数、上限を表示する。
- 変換キャッシュを利用した時点でそのファイルの更新時刻を最終利用時刻として更新する。
- 上限を超えた場合、最終利用時刻が古い完成済みMP4から削除する。
- いま生成または再利用したキャッシュは、その整理処理では保護する。
- 1ファイルだけで20GiBを超える場合、その再生に必要なファイルは削除せず残す。
- `.partial.mp4` は容量表示・自動整理の対象外とし、変換中ファイルを誤削除しない。
- 手動の「キャッシュをすべて削除」では完成済みMP4と残存partial MP4を削除する。
- 手動削除はライブラリ停止中だけ許可する。
- PlaybackCache以外のファイルは削除しない。

## データ保護

以下は一切変更・削除しない。

- 元動画
- 外部字幕
- `library.db`
- `config.json`
- `video_library.json`
- バックアップ

## CI

`tests/test_playback_cache_v091.py` で以下を検証する。

- 20GiB既定値
- 完成済みMP4だけを容量集計すること
- 古いキャッシュから削除すること
- 保護対象を削除しないこと
- 再利用したキャッシュが新しい側へ移ること
- 手動全削除でpartialも削除し、無関係ファイルを残すこと
- Windowsランチャーに容量表示・削除操作が存在すること
- バージョン整合性

既存の全6動画形式再生CI、Python 3.11/3.13回帰テスト、4,869動画fixture、Windows Installer生成も継続して必須とする。
