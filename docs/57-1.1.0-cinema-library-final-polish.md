# 1.1.0 シネマ蔵書館 最終UIポリッシュ

Issue #127 対応。

## 目的
Run #183 で統一したトップ／作品目録／詳細画面を、実機スクリーンショットを基準に最終仕上げする。

## 変更点
- ポスター未取得作品を、頭文字のみの表示から「真鍮の円章・作品名・POSTER NOT AVAILABLE」で構成する専用プレースホルダーへ変更する。
- 「上映中」「次回上映」の右端にフェード付き送りボタンを表示し、横スクロール可能であることを明示する。末尾では自動的に非表示にする。
- ポインティングデバイス利用時は、上映ストリップ上の縦ホイールを横スクロールへ変換する。ストリップ端では通常のページスクロールを妨げない。
- ヘッダーの ARCHIVE STATUS、診断、再スキャンをさらに控えめにし、「シネマ蔵書館」の看板を主役にする。
- カード／上映案内／操作ボタンの focus-visible を真鍮色で統一し、キーボードでも作品カードを開けるようにする。
- モバイルでは既存の2列作品目録と横スクロールを維持する。

## 非変更
- 再生ロジック
- TMDb照合・画像取得
- 人物リンク・お気に入りの挙動
- DBスキーマ
- 表示バージョン 1.1.0
