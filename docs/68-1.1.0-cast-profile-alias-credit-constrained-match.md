# 1.1.0 出演者顔写真 第2照合

## 背景

実機の人物名鑑HTMLでは1,001人中860人に顔写真URLがあり、141人が `PROFILE NOT AVAILABLE` だった。

141人の文字列表現を確認すると、次の傾向があった。

- 複数人物または補足混在: 4
- 改名・注記付き: 6
- カタカナ/英字系: 36
- 単純な日本語名: 95

TMDbには人物自体が存在していても、ローカル側の表示名とcredits内の `name` / `original_name` が一致せず、第1段階のexact matchでは拾えないケースがある。

例:

- 瑛太 → 永山瑛太
- 真矢みき → 真矢ミキ
- 吉田里琴 → 吉川愛
- 岡田健史 → 水上恒司
- 小西大樹 → 小西遼生
- ジョン・トラボルタ → John Travolta

## 第2照合の安全条件

exact matchに失敗した場合だけTMDb `/search/person` を使用する。

ただし、検索結果をそのまま採用しない。検索結果のperson idが、その作品のTMDb creditsに実際に含まれるperson idと一致する場合だけ候補にする。

さらに、credits内に一致するperson idが1件だけの場合に限って自動確定する。0件または複数件の場合は未照合のまま残す。

この制約により、名前検索だけで別人を採用することを防ぐ。

## 表記正規化

- `／` と `/` を人物区切りとして扱う。
- `ほか（各話ゲスト）`、`（各話ゲスト多数）`、`（声）` 等の役割注記を人物名鑑では除去する。
- `（現・...）`、`（旧・...）`、`（本名・...）` 等は元表記と括弧内表記の両方を検索候補にする。
- 例: `岡田健史（現・水上恒司）` → `岡田健史（現・水上恒司）` / `岡田健史` / `水上恒司`。

## APIキャッシュ

`/search/person` の結果は既存 `tmdb_api_cache` に30日保存する。複数作品に同じ人物が出ても同じ名前検索を繰り返さない。

## 再同期

`tmdb:people-sync-version` を1から2へ更新する。

既存ユーザーでも次回起動時に人物同期version 2が未完了と判定され、バックグラウンドで再照合する。成功後は通常起動で繰り返さない。

## 失敗時の安全性

人物検索は追加のネットワーク通信になるため、1作品分の全候補解決が完了してから既存 `tmdb_work_people` を置き換える。

途中でTMDb通信が失敗した場合は既存の人物紐付けを保持し、次回起動時に再試行する。

## テスト

- `/search/person` のAPI呼び出し。
- カタカナ名からcredits内person idへ安全に照合。
- search結果が作品credits外のperson idなら拒否。
- 改名注記の現在名でcredits exact match。
- `／` 区切りの複数人物分割。
- 役割注記の除去。
- sync version 1から2への再同期判定。
- 人物検索失敗時に既存DBリンクを保持。

表示バージョンは1.1.0のまま。
