# 1.2.3: Studio Ghibli Collection追加後の人物監査補正

## 背景

2026-09-20、ローカルの `video_library.json` に Studio Ghibli Collection 25作品を追加し、実機でTMDb作品照合・人物監査を実施した。

作品監査は全465作品で次の結果だった。

- MATCHED: 459
- REVIEW: 4
- UNMATCHED: 2

今回追加した25作品は **25/25 MATCHED** で、poster / backdropも25作品すべて取得できた。

`アーヤと魔女` はローカル年をスタジオジブリ公式に合わせて2020としている一方、TMDb movie側は2021年である。スタジオジブリ公式でも2020年12月30日にNHK総合で放送、2021年8月27日に劇場公開とされているため、同一作品の公開形態による年差であり誤マッチではない。

## 人物監査

追加後の人物監査対象は1,090人。

- PROFILE_READY: 1,057
- PERSON_NO_PROFILE: 13
- NO_MATCHED_WORK: 18
- CREDIT_PERSON_NOT_FOUND: 2

既存の監査済み残件を除くと、新たな未説明残件は **スティーブン・アルパート** 1名だった。

対象作品:

- 風立ちぬ (2013)
- TMDb movie:149870

ローカル正本はスタジオジブリ公式の出演者表記 `スティーブン・アルパート`。
TMDb creditsでは `Stephen Alpert` と英字表記されるため、従来の完全一致照合では人物リンクを確定できなかった。

## 修正

`tmdb_people_reviewed_aliases.py` に次を追加する。

```text
スティーブン・アルパート -> Stephen Alpert / Steve Alpert
```

この別名はTMDb全体検索へは使わない。

従来の監査済み別名ルールと同じく、現在のMATCHED作品credits内にある `name / original_name` と完全一致する候補だけを対象とし、person IDで重複排除した結果が1人の場合だけ採用する。

fuzzy一致、部分一致、人物名だけによる推測は追加しない。
