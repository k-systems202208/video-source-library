# 0.7.5 対応動画なし字幕の診断分離

## 背景

0.7.4の実機スキャンでは、動画は4,869 / 4,869一致し、対応字幕1,234件のうち1,227件が自動紐付された。残り7件を監査済みカタログと照合した結果、いずれもマッチングルール不足ではなく、登録済み動画側に対応する動画が存在しない字幕だった。

- `La La Land`: 動画0 / 字幕1
- `The Idea Of You`: 動画0 / 字幕1
- `北の国から`: 1983 / 1984 / 1987 / 1995 Part 1 / Part 2 のSP字幕5件。登録動画は連続ドラマ本編のみ

この7件を通常の「未紐付字幕」と同列に表示すると、異常や追加修正が必要な項目に見えるため、診断上の正常系として分離する。

## 方針

字幕マッチング、DB更新、動画・字幕ファイルには一切変更を加えない。変更対象は診断結果の分類と表示のみとする。

診断上「対応動画なし」とする条件は保守的に限定する。

1. 字幕の作品がカタログに存在し、その作品に登録動画が1本もない
2. 字幕ファイル名が明示的な `SP` / `Special` + 西暦を持ち、同じ作品の登録動画側にその年またはSP相当の動画が存在しない

上記に該当しない未紐付字幕は、従来どおり「未紐付字幕」として残す。

## 診断API

`GET /api/admin/scan-diagnostics` の結果に以下を追加する。

- `summary.orphanSubtitles`
- `orphanSubtitles[]`
  - `subtitleId`
  - `relativePath`
  - `extension`
  - `language`
  - `matchMethod`
  - `fileSize`
  - `workId`
  - `workTitle`
  - `orphanReason`

`orphanReason`:

- `NO_REGISTERED_VIDEO_IN_WORK`: 作品に登録動画がない
- `SPECIAL_VIDEO_NOT_REGISTERED`: 明示的なSP字幕に対応する登録動画がない

CSVでは `ORPHAN_SUBTITLE` セクションとして出力する。JSONでも同じ分類を保持する。

## UI

診断画面に以下を追加する。

- サマリー: `対応動画なし`
- タブ: `対応動画なし (n)`
- 理由を日本語表示
- 「登録済みカタログに対応動画がないため、自動紐付け対象外として正常に残している」旨を表示

従来の `未対応字幕`（IDX/SUB/SMI）は別分類のまま維持する。

## 実機期待値

0.7.4時点の監査済み実データでは以下を期待する。

- 動画: 4,869 / 4,869
- 字幕: 1,227 / 1,234
- 未紐付字幕: 0
- 対応動画なし: 7
- 未対応字幕: 3
- エラー: 0

## 安全性

この変更は診断表示のみであり、以下を行わない。

- 字幕の自動紐付け追加
- DBの `subtitles.video_id` 変更
- 動画・字幕ファイルの移動、改名、削除
- 対応動画がない字幕を削除または非表示化
