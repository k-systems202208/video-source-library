# 1.1.0 ヘッダー余白・初期表示・外部URL画像安定化

## 対象

Issue #145。表示バージョンは 1.1.0 のまま、関町北映画館 UI の実機確認で見つかった表示・外部接続上の問題を修正する。

## 変更内容

- PC / タブレット / スマートフォン共通で、ヘッダー内の「関町北映画館」パネルを横幅いっぱいに広げ、左右マージンを撤去。
- 作品目録の説明文を「アーカイブに収められた作品から、次の一本を。」へ変更。
- 初回ロードおよびリロードでは history.scrollRestoration = 'manual' を使い、作品目録ルートであってもページ最上部のヘッダーから表示。
- メニューから「作品目録」「上映中」「次回上映」へ移動した場合の既存スクロール動作は維持。

## 外部URLの画像欠落対策

実機では Tailscale Serve の外部 URL から開いた際、TMDb ポスターの一部がフォールバック表示になった。

現行実装は以下の条件が重なると、一時的な画像取得失敗がそのまま欠落表示として固定される。

1. /tmdb-image/... を Cache-Control: no-store で毎回取得する。
2. img の読み込み失敗時に即フォールバックへ置換し、再試行しない。
3. DB に TMDb の画像パスがあってもローカルキャッシュファイルが欠けている場合は 404 になる。

対策として以下を実装した。

- ポスター / 詳細ポスター / 背景画像は最大2回リトライする。
- TMDb画像レスポンスを private, max-age=300 とし、同一ブラウザでの不要な再取得を抑える。
- DB が MATCHED かつ画像パスを保持しているのにローカルキャッシュだけ欠落している場合、image.tmdb.org から該当画像のみオンデマンド再取得して自己修復する。
- 同一プロセス内で欠落画像の同時修復が重複しないようロックする。

## 回帰テスト

- 全端末のヘッダー全幅化。
- 作品目録の新しい説明文。
- 初回ルーティング時の最上部表示。
- 画像リトライ用 JavaScript の存在。
- TMDb画像配信のキャッシュヘッダー。
- 欠落ポスターキャッシュのオンデマンド修復。
- 既存キャッシュがある場合に再ダウンロードしないこと。
- REVIEW / UNMATCHED は自己修復対象にしないこと。
