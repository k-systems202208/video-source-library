## 実機検証の変更

`validate_real_library.py` は、`video_id IS NULL` を一律エラーとしない。

未紐付のうち診断上 `orphanSubtitles` に分類された「対応動画なし」は正常系として扱い、`unmatchedSubtitles` だけを未解決として失敗させる。

既定期待値:

```text
works                  440
videos                 4869
supported subtitles    1234
matched subtitles      1227
orphan subtitles       7
unsupported subtitles  3
```

加えて MISSING / NEW_FILE / 診断エラーは 0 を要求する。

## バージョン管理

Python 側のバージョンは `windows-installer/src/app_version.py` の `APP_VERSION` を共通定義として Launcher / Server から参照する。

Inno Setup 側は `VideoLibrary.iss` に同じ値を保持し、回帰テストで共通定義と一致することを固定する。

0.7.7 の値は `0.7.7`。
