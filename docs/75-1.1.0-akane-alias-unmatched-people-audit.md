## 茜音

ローカルの人物名 `茜音` は実写版『凍牌〜裏レート麻雀闘牌録〜』の公式キャスト表記と一致している。

一方、TMDb tv:113414 のcredits監査では対応人物が `紅音` と登録されているため、ローカル名を変更せず、監査済みcredits別名として `茜音 → 紅音` を追加する。

既存の第6照合と同じく、この別名はTMDb全体検索には使用しない。現在のMATCHED作品credits内で完全一致するperson IDが1人だけの場合に限って採用する。

## 未MATCHED人物の監査強化

これまで `NO_MATCHED_WORK` の人物は、人物名と件数だけが分かり、どのローカル作品に属するかは人物監査CSVから追跡できなかった。

人物監査JSON/CSVへ `localWorks` を追加する。

`localWorks` には、その人物が登録されている全ローカル作品について次を含める。

- 作品名
- 年または期間
- `match_status`
- `media_type`
- `tmdb_id`

例:

- `Unmatched Work [UNMATCHED]`
- `Ready Work [MATCHED movie:101]`
- `半分の月がのぼる空 (2006) [UNMATCHED]`

`MATCHED` 以外の作品も出力するため、次回監査から `NO_MATCHED_WORK` の20人を作品単位で直接調査できる。
