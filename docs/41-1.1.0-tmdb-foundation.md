# 1.1.0 TMDb連携基盤

## 方針
TMDb API v3のApplication AuthenticationにはAPI Read Access TokenのBearer認証を使用する。トークンをURL queryへ付与しないことで、URL履歴やエラー文字列へcredentialが混入しにくい構成にする。

公式: https://developer.themoviedb.org/docs/authentication-application

## トークン設定
優先順位は次のとおり。

1. 環境変数 `VIDEO_LIBRARY_TMDB_TOKEN`
2. `%LOCALAPPDATA%\VideoLibrary\config.json` の `tmdbReadAccessToken`

環境変数方式ならトークンをアプリ設定ファイルへ保存しない。Windowsランチャーの「TMDb設定」からローカル設定へ保存する場合も、保存済みトークン値は画面へ再表示せず、ログにも出さない。

## HTTPクライアント
`tmdb_client.py` は `Authorization: Bearer ...` を使用し、`api_key` / `access_token` 等をquery parameterとして渡す呼び出しを拒否する。HTTP/接続/JSONエラーはトークンを含まない固定メッセージへ変換する。

## DB
Schema 5で `tmdb_work_links` と `tmdb_api_cache` を追加する。既存DBは再作成せず `CREATE TABLE IF NOT EXISTS` でmigrationし、お気に入り・視聴位置・再生回数などを保持する。

## この段階で行わないこと
- 440作品の自動マッチング
- poster/backdrop画像取得・表示
- creditsのTMDb人物ID取込
- 同姓同名人物の統合
