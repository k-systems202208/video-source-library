# 自宅動画ライブラリ 1.2.3

## 概要

1.2.3は、Studio Ghibli Collection 25作品を追加した実機TMDb監査で見つかった人物名の表記差を安全に補正するパッチ版。

`風立ちぬ` の公式出演者「スティーブン・アルパート」と、TMDb creditsの `Stephen Alpert` を監査済み別名として結び付ける。

## 変更

- `スティーブン・アルパート -> Stephen Alpert / Steve Alpert` を監査済みcredits別名へ追加
- 別名は現在のMATCHED作品credits内だけで利用
- 完全一致かつperson IDが1件に確定する場合だけ採用
- fuzzy / 部分一致は追加しない
- people sync version 9 -> 10
- people audit version 8 -> 9
- application version 1.2.2 -> 1.2.3

## 実機監査の確認値

追加後の作品数は465作品。

- MATCHED: 459
- REVIEW: 4
- UNMATCHED: 2

今回追加したStudio Ghibli Collection 25作品は25/25 MATCHEDで、poster / backdropもすべて取得済み。

人物監査は1,090人で、新規未説明残件はスティーブン・アルパート1名だった。本版で再同期・再監査対象とする。

## 継続仕様

- SQLite schema: 8
- TMDb matcher: 8
- PWA shell: v6
- Windowsランチャーの作品表示設定・作品名フィルターを維持
- ブラウザにvisibility管理UI/APIは持たない
- metadata再取込でも `is_visible` を保持
- 元動画・字幕を変更しない
- 既存の利用者状態を保持

1.2.2へ上書きインストール可能。

schema migrationはない。インストール後、人物同期version 10 / 人物監査version 9により既存DBでも再評価される。
