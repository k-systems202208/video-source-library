# 1.1.0 TMDb作品マッチングと監査

## 目的

Issue #78 のうち、Issue #91で追加したTMDb認証・schema 5・APIキャッシュ基盤を利用して、登録作品を安全側でTMDbへ紐付ける。

## 照合ルール

- 作品名、公開年、作品種別（movie / tv）を使って候補を評価する。
- 映画カテゴリはmovie、ドラマカテゴリはtvを優先する。
- アニメは映画・TVの両方を検索し、複数話ならtvを加点する。1ファイル作品は種別を強制しない。
- Unicode NFKC正規化、大小文字差、空白・記号差を吸収してタイトル類似度を計算する。
- 公開年完全一致を加点し、3年以上の差は減点する。
- 自動確定は confidence 0.92以上、タイトル類似度0.95以上、2位との差0.08以上をすべて満たす場合だけに限定する。
- 条件を満たさない候補は `REVIEW` または `CANDIDATE` とし、自動確定しない。

## 保存内容

`tmdb_work_links` に以下を保存する。

- TMDb media type / ID
- match status / confidence
- matched title / year
- poster path / backdrop path
- overview
- synced timestamp

検索レスポンスは7日、作品詳細は30日を目安に `tmdb_api_cache` へ保存する。poster/backdropはこの段階ではTMDbの参照pathを保存し、画像バイナリの取得・Web UI表示は後続段階で行う。

## 監査

ランチャーの `TMDb設定` ダイアログから `TMDb作品照合` を実行できる。登録作品を順に照合し、以下を表示・出力する。

- `MATCHED`: 高信頼で自動確定
- `REVIEW`: 一定以上の候補だが候補差不足などで要確認
- `CANDIDATE`: 低信頼候補
- `UNMATCHED`: 候補なし
- `ERROR`: 通信等で照合できなかったもの

出力先は `%LOCALAPPDATA%\VideoLibrary\diagnostics`。

- `tmdb-match-audit-YYYYMMDD-HHMMSS.json`
- `tmdb-match-audit-YYYYMMDD-HHMMSS.csv`

CSVはUTF-8 BOM付きでExcelから開きやすくする。API Read Access Tokenはレポート、URL query、ログへ出力しない。

## 安全性

- TMDb未設定時も既存ライブラリ機能は利用可能。
- 低信頼・複数候補を自動確定しない。
- 元動画、字幕、再生キャッシュ、視聴状態を変更しない。
- 通信エラー時はその作品を `ERROR` として監査レポートへ残し、既存の紐付けを破壊しない。
