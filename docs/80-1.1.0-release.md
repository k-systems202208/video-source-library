# 自宅動画ライブラリ 1.1.0

## 概要

1.0.0で固定した動画再生基盤を維持したまま、TMDb連携、作品画像、人物名鑑、主な出演者／声優のプロフィール画像、レトロ映画館UIを追加した1.1.0正式版。

## 1.1.0の主な追加・改善

### TMDb作品連携
- API Read Access TokenによるTMDb連携
- 映画 / TVを安全側で照合
- overview、poster、backdropを作品詳細へ追加
- matcher version 8
- 低信頼候補、集約作品、構造不一致は自動確定しない
- TMDb監査JSON / CSVをdiagnosticsへ出力

### 関町北映画館UI
- Web UIをレトロ映画館デザインへ刷新
- PC / Tablet / Smartphone対応
- 作品ポスター / 背景画像
- 作品詳細、人物検索、上映中、次回上映、作品目録を映画館UIへ統一

### 人物名鑑
- 監督／演出から登録作品を検索
- 主な出演者／声優から登録作品を検索
- 主な出演者／声優は、安全にTMDb人物IDを確定できた場合のみ顔写真を表示
- 監督／演出はテキスト名鑑のみ
- people sync version 9
- people audit version 8
- 実機人物監査で未説明の要確認残件を0件まで整理

### TMDb画像キャッシュ安全化
- 作品画像キャッシュをwork_idだけでなく現在のremote_path hashでも識別
- TMDb作品リンクを修正した後に、同じwork_idの古い別作品画像を再利用しない
- 旧キャッシュを破壊的に削除せず、安全に新キャッシュへ移行

### PWA / ドキュメント
- PWA shellをv4へ更新
- オフライン画面とmanifestを「関町北映画館」へ統一
- README / 基本設計 / DB設計 / 画面設計 / API設計を現行1.1.0へ更新
- SQLite schema 7を現在仕様として明文化

## 継続する1.0.0の主要機能

- 440作品 / 4,869動画のSQLite索引
- Windowsランチャー / ユーザー権限インストーラー
- HTTP Range動画配信
- Tailscale Serve
- PWA
- 視聴状態 / 続きから見る / 履歴 / お気に入り
- SRT / VTT / ASS / SSA外部字幕
- 日本語音声優先
- ブラウザ非互換動画のH.264 + AAC変換
- PlaybackCache 20GB上限 / LRU整理
- バックアップ / 復元
- 全件再生監査

## 更新方法

既存の1.0.0 / 1.1.0開発版へ上書きインストールできる。

利用者データは `%LOCALAPPDATA%\VideoLibrary` に保持され、アンインストールや上書きインストールで自動削除しない。
