# 1.1.0-a3 TMDb同期の一時エラー再試行

## 実機で判明した問題

matcher v2で440作品を再同期した際、325件目付近でTMDb APIからHTTP 502が返り、同期全体が中断した。
その時点の途中結果は MATCHED 286 / REVIEW 32 / UNMATCHED 8 だった。

## 修正

- HTTP 429 / 502 / 503 / 504 を一時エラーとして自動再試行する。
- URLError / TimeoutError / OSError も一時的な接続失敗として自動再試行する。
- 既定は初回要求に加えて最大3回再試行する。
- Retry-Afterヘッダーがある場合はその待機時間を使用する。
- Retry-Afterがない場合は 1秒、2秒、4秒の指数バックオフを使用する。
- 401 / 403 / 404など再試行しても改善しないHTTPエラーは従来どおり即時失敗する。
- TokenをURLや例外文へ出さない既存の安全策を維持する。

## 再実行時の挙動

TMDb検索結果はDBへキャッシュされているため、途中まで成功した同期を再実行しても、既にキャッシュ済みの検索をすべてネットワークから取り直す必要はない。
matcher version 2の確定マーカーは440作品すべての処理が成功した時点でのみ保存されるため、途中失敗後の再実行でも旧誤マッチの再評価は継続される。
