# 1.2.0 作品表示設定

## 目的

関町北映画館の通常画面に表示する作品を、Ownerが作品単位で限定できるようにする。

この機能は作品削除ではなく「館内表示対象」の設定である。非表示にしても作品・動画・TMDb情報・お気に入り・視聴履歴等は保持する。

## DB

SQLite schema 8。

`works` に次を追加する。

```sql
is_visible INTEGER NOT NULL DEFAULT 1 CHECK(is_visible IN (0, 1))
```

- `1`: 表示中
- `0`: 非表示
- schema 7以前の既存作品はmigration時に1
- 新規作品もDEFAULT 1
- metadata importerは `is_visible` をINSERT/UPDATE項目に含めないため、再取込で設定を上書きしない

## 通常表示

通常の利用者向け一覧は `is_visible=1` の作品だけを対象にする。

対象:

- 作品目録
- 検索結果
- 上映中
- 次回上映
- 最近見た作品
- お気に入り作品
- お気に入り動画
- 視聴履歴
- 監督／演出 人物名鑑
- 主な出演者／声優 人物名鑑
- 人物からの作品検索
- 作品数・カテゴリ別件数

## 直接アクセス

非表示はアクセス制御ではない。

次はvisibilityに関係なく利用できる。

- `GET /api/works/{id}`
- `GET /api/works/{id}/videos`
- `GET /api/videos/{id}`
- `#/work/{id}`

このためブックマーク済みの作品や、管理画面から開いた非表示作品も確認・再生できる。

## Owner管理API

### 一覧

通常:

```
GET /api/works
```

表示中だけを返す。

Ownerのみ:

```
GET /api/works?visibility=visible
GET /api/works?visibility=hidden
GET /api/works?visibility=all
```

### 更新

Ownerのみ:

```
PUT /api/admin/works/visibility
Content-Type: application/json

{
  "workIds": [12, 15, 18],
  "visible": false
}
```

最大1000件を一度に更新できる。

## UI

Ownerには作品目録上部に「表示設定」ボタンを表示する。

管理モード:

- `表示中 / 非表示 / すべて` の一覧切替
- 各作品カードにチェックボックス
- 現在読み込まれている一覧を一括選択
- 選択作品を一括表示
- 選択作品を一括非表示
- カード上に「表示中 / 非表示」を表示

作品詳細にもOwner用の表示設定ボタンを追加する。

- `◉ 表示中`
- `⊘ 非表示`

通常画面へ戻ると表示設定モードは解除し、表示中作品だけの一覧へ戻る。

## セキュリティ

- 通常の `GET /api/works` は匿名読み取りでも利用可能だが、表示中だけ
- `visibility=hidden/all` はOwnerのみ
- visibility更新もOwnerのみ
- Tailscale一般利用者は非表示作品一覧や管理操作を利用できない

## 既存データ

非表示にしても以下は削除しない。

- `works`
- `videos`
- `video_files`
- `tmdb_work_links`
- `tmdb_people`
- `user_work_state`
- `user_video_state`
- PlaybackCache
- TMDbImages

表示へ戻した時点で以前の状態をそのまま再利用する。
