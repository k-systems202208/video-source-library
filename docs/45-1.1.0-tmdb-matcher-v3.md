# 1.1.0 TMDb matcher v3（440作品監査対応）

## 実機監査

`tmdb-match-audit-20260915-222637.csv` で440/440完走を確認した。

- MATCHED: 387
- REVIEW: 42
- UNMATCHED: 11

監査では、`日本映画・ドラマ` のような複合カテゴリで、連続ドラマと同名・同年の映画候補が競合した際にmovie側へ寄るケースが残っていた。また、副題・括弧読み・和英併記などの表記差により正解候補がREVIEW/UNMATCHEDへ落ちるケースも確認した。

## matcher v3

- matcher versionを3へ更新し、v2で確定した既存MATCHEDも初回だけ再評価する。
- `videos.content_type` の `EPISODE` / `MOVIE` 件数を作品種別の補助情報として利用する。
- content typeだけで判断できない場合、単年かつ3ファイル以上の作品はtv側へ弱い優先度を与える。
- movie/tv候補自体は両方保持し、作品種別の補助情報は候補順位のtie-breakにのみ使用する。
- 複数年にまたがるローカル作品は、開始年が一致した単一movieへ自動MATCHEDしない。候補はREVIEWへ残す。
- タイトル比較ではNFKCに加えて、括弧付き読み、副題区切り、スラッシュ併記、`YASHA-夜叉-` のような和英ダッシュ併記を比較候補へ展開する。
- `MATCHED` の高信頼条件、REVIEW/UNMATCHED時に画像を公開しない安全策、API検索キャッシュ、画像キャッシュは維持する。

## 代表テスト

- `プライド`: 同名同年movie/tvの競合で、連続作品の文脈からtvを選択する。
- `TRICK`: movie候補の素点がわずかに高くても、エピソード実体と年一致からtvを選択できる。
- `男はつらいよ 1969-2019`: シリーズ全体を第1作movieへ自動確定しない。
- `YASHA-夜叉-` / `Q10（キュート）` / `HiGH&LOW ～THE STORY OF S.W.O.R.D.～` / `ミス・シャーロック/Miss Sherlock`: 表記差を高一致として評価する。
- matcher version 2から3への移行時に旧MATCHEDを再評価し、完走後だけversion 3マーカーを保存する。
