# 1.1.0 出演者顔写真 第5照合（作品credits内人物の別名）

## 実機監査結果

`tmdb-people-audit-20260918-141806.csv` では997人を監査し、第4照合後に次の結果となった。

- PROFILE_READY: 938（前回891から+47）
- PERSON_NO_PROFILE: 7（前回4から+3）
- PERSON_SEARCH_NOT_IN_CREDITS: 10（前回60から-50）
- CREDIT_PERSON_NOT_FOUND: 26
- NO_MATCHED_WORK: 16

未解決は59人。特に `CREDIT_PERSON_NOT_FOUND` 26人は、ローカル人物名による `/search/person` が0件でも、対象作品creditsには別表記の人物が存在する例が多い。

例:

- ジョン・トラボルタ ↔ ジョン・トラヴォルタ / John Travolta
- ウィリアム・サドラー ↔ William Sadler
- 小原裕貴 ↔ Yuki Kohara
- 藤井萩花 ↔ Fujii Shuuka

## 第5照合

第1〜4照合で確定しなかった人物だけを対象にする。

1. 対象作品creditsのcastをbilling order順に並べ、上位20人を確認する。
2. 各cast person IDの `/person/{id}` を取得する。
3. person detailsの `name` / `original_name` / `also_known_as` を正規化する。
4. ローカル人物名および改名注記から生成した検索候補と、正規化後に完全一致するか確認する。
5. 対象作品credits内で一致するperson IDが1人だけの場合に限り自動確定する。
6. 0人または複数人の場合は未照合のまま残す。

人物検索結果ではなく、対象作品creditsに実際に含まれるperson IDだけを候補にするため、別名を使っても候補範囲は作品内に限定される。

## APIキャッシュ

`/person/{id}` の結果は `tmdb_api_cache` に30日保存する。

同じ人物が複数作品に登場する場合や、1作品に複数の未解決人物がいる場合でも、同じperson IDの人物詳細を繰り返し取得しない。

## API負荷制御

作品creditsの全人物を無制限に照会せず、billing order上位20人までを対象にする。ローカル側の「主な出演者／声優」との照合用途なので主要castを優先する。

## version

- `tmdb:people-sync-version` 4 → 5
- `tmdb:people-audit-version` 3 → 4

アップデート後は人物同期version 5を一度だけ実行し、その後に人物監査version 4を生成する。

## ログ

バックグラウンド人物同期と手動TMDb同期に `第5照合回収` 件数を追加する。

## テスト

- `/person/{id}` 人物詳細API。
- 対象作品credits内の人物の `also_known_as` とローカル名が完全一致する場合の第5照合。
- 複数人物が同じ別名を持つ場合は拒否。
- 部分一致のみの場合は拒否。
- 人物詳細APIキャッシュ。
- people sync version 4 → 5。
- people audit version 3 → 4。

表示バージョンは1.1.0のまま。
