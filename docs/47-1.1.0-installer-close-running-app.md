# 1.1.0 上書きインストール時の旧プロセス終了

## 実機で判明した問題

2026-09-16 20:51に生成されたTMDb監査CSVは新しい日時だったが、内容は旧matcher v2の挙動だった。

- 既存MATCHED 387件がすべて `EXISTING_MATCH`
- `Q10` / `YASHA-夜叉-` / `HiGH&LOW` / `ミス・シャーロック/Miss Sherlock` のconfidenceが旧値のまま
- `TRICK` も旧movie候補のまま

この組み合わせから、上書きインストール前から起動していた旧 `VideoLibrary.exe` がインストール後も動作し、その旧プロセス上でTMDb同期が実行された可能性が高いと判断した。

## 修正

Inno Setupに以下を明示する。

- `CloseApplications=yes`
- `CloseApplicationsFilter=VideoLibrary.exe`
- `RestartApplications=no`

これにより上書き前の旧実行プロセスを閉じ、インストール後は `[Run]` から新しい `VideoLibrary.exe` を起動する。

## 監査バージョン

TMDb監査CSV/JSONには既に `appVersion` / `matcherVersion` を記録する。現在のmainは表示バージョン `1.1.0`、matcher version `4`。

次回実機監査では、CSV先頭列に `appVersion=1.1.0`、`matcherVersion=4` が出力されていることを最初に確認する。
