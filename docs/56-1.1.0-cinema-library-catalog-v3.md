# 1.1.0 シネマ蔵書館 第3段階: トップ／作品目録

Issue #125。Run #179で仕上げた作品詳細画面のデザイン言語を、トップ／作品目録へ展開する。

## 変更内容
- 「上映中 / NOW SHOWING」「次回上映 / COMING SOON」を上映案内カード風に強化
- 作品目録に `PRIVATE SCREENING CATALOG` / `作品目録 / CATALOG` と検索結果件数を追加
- 検索・並び替えを目録検索の操作盤として整理
- カテゴリを券札／館内メニュー風に統一
- ポスターカードを詳細画面と同じ真鍮・えんじ・アイボリーの階層へ統一
- ヘッダー右側の管理情報を控えめにし、看板を主役化
- モバイル2列表示を維持

## 維持するもの
- 表示バージョン `1.1.0`
- 検索、カテゴリ、並び替え、60件ページングのロジック
- 再生、TMDb、人物リンク、お気に入り、DBスキーマ
- 第2段階の作品詳細デザイン

## テスト
`tests/test_cinema_library_catalog_v3_v110.py` で、見出し、検索・並び替え・カテゴリ、件数同期、上映中／次回上映、既存詳細画面の維持を確認する。
