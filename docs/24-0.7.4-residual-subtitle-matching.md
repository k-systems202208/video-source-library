# 0.7.4 残り字幕の安全な追加照合

Issue #43 で、0.7.3 実機スキャン後に残った未紐付字幕 67 件を再分析し、追加で安全に一意判定できる 60 件だけを自動紐付けする。

## 方針

- 同一作品内の既存照合を最優先し、既存仕様を壊さない。
- Season/Episode が複数候補になる場合、字幕と動画の枝フォルダー共通度で一意に決まる場合だけ採用する。
- 区切り文字だけが違う stem は、英数字の正規化後に一意なら採用する。
- 作品ルート直下の枝フォルダーに登録動画が 1 本だけなら、その枝内字幕を一意候補とする。
- 画質・codec 等の技術トークンを除外した release stem が一意なら採用する。
- 2 分割映画では、動画側 `TrimN` / `PartN` 等と字幕側末尾番号が同じで、作品名 stem が一致する場合だけ採用する。
- 複数候補、対応動画なし、意味的な別トラックは自動紐付けしない。
- 元動画・字幕ファイルの移動・改名・削除は行わない。

## 実データ再分析

0.7.3 相当ロジックを 4,869 動画と旧診断の 880 未紐付字幕に再適用すると、現行仕様で 813 件が紐付き、67 件が残ることを再現できた。

追加ルールで安全に一意判定できる内訳は次の通り。

- 枝フォルダーを使った Episode 一意化: 43 件
- 区切り記号差の canonical stem 一致: 13 件
- 2 分割ファイル番号一致: 2 件
- 枝フォルダー内単一動画: 1 件
- release 技術トークン差のみ: 1 件

合計 60 件。残る 7 件は対応動画自体が登録されていない字幕のため、自動紐付けしない。
