# 1.1.0 UI停止修復と館名パネル余白調整

## 対象

Issue #147。PR #146 適用後の実機確認で、トップページのデータが表示されず、左側の館内メニューも動作しない回帰を確認した。

## 原因

背景画像の再試行処理へ変更した際、作品詳細表示の JavaScript が次のような連結になっていた。

- backdrop の if 文
- 直後の const 宣言

両者の区切りがなく JavaScript の構文エラーとなり、video-library.html の inline script 全体が解析されなかった。そのため初期データ取得、作品描画、左側メニューのイベント登録がすべて停止していた。

## 修正

- backdrop 処理をブロック付き if 文へ変更し、構文エラーを解消。
- 関町北映画館のヘッダー外枠は通常の余白へ戻した。
- 中央の金色の館名パネルは横幅いっぱいではなく、文字幅に合わせた fit-content とした。
- PC / タブレット / スマートフォンの中央寄せは維持。
- Node.js の --check で video-library.html の inline JavaScript を検査する回帰テストを追加。

## 再発防止

Python の文字列ベースUIテストだけでは JavaScript の構文エラーを検出できなかった。今後は CI の通常ユニットテスト内で Node.js 構文チェックも実施し、HTML内のJavaScriptが解析不能な状態でインストーラーを生成しない。
