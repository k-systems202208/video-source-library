# 1.1.0 シネマ蔵書館 ベースデザイン

## 目的
A案のクラシックな映画館テイストを、現行UI構造と機能を維持したまま適用する。名称は「シネマ蔵書館」とする。

## 第1段階の変更
- アプリ名を「シネマ蔵書館」へ変更
- キャッチコピーを「映画で、また会える。」へ変更
- 黒／焦げ茶を基調に、えんじ・真鍮・アイボリーをアクセントとして採用
- 「続きから見る」を「上映中」、「次に見る」を「次回上映」へ変更
- 作品カードを額縁風のポスター主体デザインへ変更
- 詳細画面、ボタン、人物リンク、エピソード枠を同じクラシックシネマ調へ統一
- モバイル表示を維持

## 今回変更しないもの
再生ロジック、TMDb照合・画像取得、人物リンク、お気に入り等の機能ロジック、DBスキーマ、表示バージョン1.1.0は変更しない。

## 次段階候補
実機確認後、サイドナビゲーション、劇場看板風ロゴの強化、カテゴリの映画館語彙化、詳細画面の情報配置を検討する。
