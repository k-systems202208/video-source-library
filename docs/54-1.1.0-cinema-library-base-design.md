# 1.1.0 シネマ蔵書館 ベースデザイン

Issue #118。既存の動画ライブラリ機能を維持したまま、A案のクラシック映画館テイストを「シネマ蔵書館」ブランドとして導入する。

## 変更

- ブラウザ、PWA、Windowsランチャーの表示名を「シネマ蔵書館」に統一。
- 黒〜焦げ茶を基調に、ワインレッド、真鍮/ゴールド、アイボリーを使用。
- 見出しに明朝系フォントを使用し、映画館のプログラムや看板を想起する階層を追加。
- 一覧カードはポスターを額装するような枠と陰影へ変更。
- 作品詳細は既存backdropを活かし、暗いグラデーションとポスター額縁を追加。
- 「続きから見る」を「上映中」、「次に見る」を「次回上映」、「作品一覧へ戻る」を「作品目録」へ変更。
- 検索、再生、TMDb、人物リンク、視聴履歴、スキャンなどの機能ロジックは変更しない。

## 互換性

- 表示バージョンは1.1.0を維持。
- matcherVersion 7を維持。
- `VideoLibrary.exe` やインストーラー内部識別子は既存上書き更新との互換性のため変更しない。
- モバイル用CSSも同一テーマ内で調整する。
