# 0.9.2 実ライブラリ全件再生監査

## 目的

v1.0公開前に、登録済み4,869動画の再生経路を実ファイル単位で監査する。

この監査は動画を4,869本すべて実時間再生するものではない。各ファイルをffprobeで解析し、現在のブラウザ直接再生条件とFFmpeg互換再生条件に照らして、再生経路が成立するかを全件判定する。

## 監査項目

各動画について以下を記録する。

- 登録動画ID / 外部ファイル番号
- 相対パス（絶対パスはレポートに出さない）
- 拡張子 / コンテナ形式
- 映像Codec
- 全音声Codec / 言語タグ / 音声トラック数
- 日本語音声の有無
- 優先対象音声トラック
- 外部字幕件数
- 埋め込み字幕ストリーム数
- 再生経路
  - `DIRECT`: ブラウザへそのまま配信可能
  - `TRANSCODE`: FFmpegでH.264 + AAC MP4へ変換して再生
  - `NO_ROUTE`: 現状の再生経路では再生できない
- `NO_ROUTE` の理由 / ffprobeエラー

## 判定ルール

### DIRECT

0.9.0以降の実際の再生ロジックと同じ条件を使う。

- MP4/M4V: H.264 + AAC/MP3
- WebM: VP8/VP9/AV1 + Opus/Vorbis
- 日本語音声が第2トラック以降にあり日本語優先のためトラック選択が必要な場合はDIRECTにせずTRANSCODE

### TRANSCODE

DIRECT条件を満たさないが、同梱FFmpegが利用可能で映像ストリームが存在する場合。

### NO_ROUTE

以下を明示する。

- `MISSING_FILE`: 登録済み実ファイルが存在しない
- `PATH_ESCAPE`: 登録相対パスが動画ルート外を指す
- `PROBE_ERROR`: ffprobeで解析できない
- `NO_VIDEO_STREAM`: 映像ストリームがない
- `FFMPEG_NOT_AVAILABLE`: 直接再生不可かつFFmpegがない

v1.0受入条件は `NO_ROUTE = 0` とする。

## 出力

Windowsランチャーから「全件再生監査」を実行すると、以下にJSONとCSVを出力する。

`%LOCALAPPDATA%\VideoLibrary\diagnostics`

CSVはExcelで文字化けしにくいUTF-8 BOM付きとする。

レポートには絶対パスを含めず、動画ルートからの相対パスだけを保存する。

## 安全性

- 元動画を変更しない
- 字幕ファイルを変更しない
- PlaybackCacheを作成しない
- SQLiteの動画・ユーザー状態を変更しない
- ffprobeによる読み取り専用解析だけを行う

## CI

`tests/test_playback_audit_v092.py` で以下を検証する。

- 日本語第2音声の優先とTRANSCODE判定
- MP4直接再生判定
- FFmpegなし時のNO_ROUTE
- 映像ストリームなし判定
- 音声・字幕・再生経路の集計
- JSON/CSV出力
- 外部字幕件数のDB結合

既存のPython 3.11/3.13全回帰テスト、全6動画形式playback-formats、440作品・4,869動画fixture、Windows Installer生成も引き続き必須とする。
