# 1.1.0 ソース・ドキュメント最終整合性監査

## 目的

1.1.0をほぼ完成状態として扱う前に、mainの実装と「現在仕様」を説明するドキュメントが一致しているかを再確認した。

過去のPhase別・matcher別文書は、その時点の判断を残す実装履歴として扱い、現在仕様へ機械的に書き換えない。

## 現行固定値

- app: 1.1.0
- SQLite schema: 7
- TMDb matcher: 8
- people sync: 9
- people audit: 8
- 実機基準: 440作品 / 4,869動画
- 主な出演者／声優: 顔写真あり
- 監督／演出: テキスト名鑑のみ、顔写真なし

people sync 9は、監督写真対応版を一度配布した後に機能を撤回したため、version番号を巻き戻さず単調増加を維持している。

### 結果

- schema 7の `DIRECTOR` roleは配布済みDB互換のため残す。
- 通常人物同期はCASTのみで、監督写真用同期は撤回済み。
- matcher 8 / people audit 8の安全ルールに未説明の緩和はない。
- TMDb作品画像は `work_id + remote_path hash` で識別し、古い別作品画像を再利用しない。
- 人物画像はTMDb person IDをキーとするため作品画像修正の対象外。
- TODO / FIXMEとして残っている新規対応必須箇所は確認されなかった。

## PWA shellの最新化

Service Worker shell cacheを `video-library-shell-v4` へ更新した。

理由:

- manifest / offline shell / iconはcache-first。
- cache名を据え置くと既存PWAで古いshellが残る可能性がある。

同時に次を現行「関町北映画館」へ統一した。

- `offline.html` のtitle / H1 / 配色
- `manifest.webmanifest` のbackground / theme color

Service Workerでは引き続き次をキャッシュしない。

- `/api/*`
- `/video/*`
- `/subtitle/*`
- `/tmdb-image/*`
- `/tmdb-person-image/*`
