# 1.1.0-a2 TMDb複合カテゴリ照合修正

## 実機監査で判明した問題

2026-09-15の440作品監査で、`日本映画・ドラマ` / `海外映画・ドラマ` がmovieのみ検索されていた。
原因はカテゴリ文字列に「映画」が含まれるとmovieのみを返す判定順序だった。

## 修正

- 「映画」と「ドラマ」の両方を含むカテゴリはmovie/tv両方を検索する。
- 単独映画カテゴリはmovie、単独ドラマカテゴリはtvを維持する。
- matcher version 2 をDB内TMDbキャッシュへ記録する。
- version 2へ初回移行するときだけ、旧matcherで作られた既存MATCHEDも再評価する。
- 再評価が最後まで成功した場合だけversion markerを保存する。中断時は次回再試行する。
- version 2移行後の既存MATCHEDは従来どおり保護する。
- REVIEW/UNMATCHEDではTMDb画像URLを公開しない既存安全策を維持する。

## 実機再監査

修正版でTMDb同期を再実行し、440作品のMATCHED/REVIEW/UNMATCHEDと誤マッチを再確認する。
特に日本ドラマと「ブレイキング・バッド」がtv候補として評価されることを確認する。
