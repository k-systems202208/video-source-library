# 1.1.0 TMDb matcher v5

## 実機監査

2026-09-16 21:56生成の `tmdb-match-audit-20260916-215651.csv` を全440件確認した。

- appVersion: `1.1.0`
- matcherVersion: `4`
- MATCHED: 420
- REVIEW: 14
- UNMATCHED: 6

v4で旧誤マッチの大半は解消したが、残り20件のうち検索方法の改善で解消可能なケースが残った。

## v5の対象

代表的な未解決ケース:

- `TRICK` — 1999年movie候補が上位
- `GOOD LUCK!!` — `Good Luck Jeffrey Brown` が候補
- `BLOODY MONDAY` — `Bloody Mondays & Strawberry Pies` が候補
- `アンタッチャブル〜事件記者・鳴海遼子〜` — unrelated movieが候補
- `LIAR GAME` — 正しいtv 13967を取得しているがTMDb日本語表記 `ライアーゲーム` との表記差でLOW_CONFIDENCE

## 修正

### 1. matcher version 5

監査CSV/JSONの `matcherVersion` を5へ上げる。表示アプリバージョンは `1.1.0` のままとする。

### 2. v4 MATCHEDを保持

v4実機監査でMATCHEDとなった420件はv5初回同期でも既存紐付けを保持する。

v5は検索経路の改善が目的なので、REVIEW / UNMATCHEDを再検索対象とする。matcher v3以前のMATCHEDは既知の旧誤マッチを含むため、従来どおり再評価する。

### 3. 検索クエリの拡張

- 年指定検索で強候補が得られなければ年なし検索を行う。
- 副題区切りの前後を検索候補へ追加する。
- 末尾の `!` / `?` を除いた検索候補も追加する。
- media typeごとに強候補を判定し、movie側の候補を理由にtv側の追加検索を打ち切らない。

### 4. 監査済み別名

TMDb IDをハードコードせず、同一作品であることを監査済みの表記差だけをタイトル別名として扱う。

- `LIAR GAME` ↔ `ライアーゲーム`
- `BLOODY MONDAY` ↔ `ブラッディ・マンデイ`

### 5. search cache namespace更新

検索キャッシュを `tmdb:search:v2:` namespaceへ変更する。REVIEW / UNMATCHED再検索時にv4以前の検索結果へ固定されず、新しい検索経路で評価できる。

### 6. 完全一致＋開始年一致の優位性

タイトル完全一致・開始年完全一致の候補が、2位候補よりタイトルまたは年で明確に優位な場合は、ランキング差0.05以上を自動確定可能な根拠として扱う。

同年・同名候補同士はこの緩和の対象外で、従来どおり保守的にREVIEWへ残す。

## 意図的に残す例外

次は1つのTMDb作品へ自動確定させない。

- `男はつらいよ`
- `仁義なき戦い`
- `福岡恋愛白書`

いずれもローカル上は複数作品・複数期をまとめた項目である。

また、現状TMDb検索で候補が得られていない以下も誤候補へ無理に紐付けない。

- `3年B組金八先生 第6シリーズ`
- `妻は、くノ一〜最終章〜`
- `殺人分析班シリーズ`
