# 1.3.0 Tailscaleユーザーごとの作品表示設定

## 目的

1.2.xでは `works.is_visible` を全利用者共通の表示設定として使用していた。

1.3.0ではこの共通設定を残したまま、Tailscale Serveで識別された利用者ごとに作品の表示／非表示を設定できるようにする。

ブラウザ側へ設定画面や管理APIは追加せず、設定変更は引き続きWindowsランチャーだけで行う。

## 利用者識別

既存のTailscale利用者識別をそのまま利用する。

Tailscale Serveからバックエンドへ渡されるidentity headerを解析し、既存の `users / user_identities` へ紐付ける。

- `Tailscale-User-Login`
- `Tailscale-User-Name`
- `Tailscale-User-Profile-Pic`

アプリHTTPサーバーは従来どおりlocalhostへだけbindする。

参照:
- https://tailscale.com/docs/features/tailscale-serve
- https://tailscale.com/docs/concepts/tailscale-identity

## DB

SQLite schemaを8から9へ更新する。

共通設定は既存の `works.is_visible` を継続利用する。

追加テーブル:

```sql
CREATE TABLE user_work_visibility (
    user_id INTEGER NOT NULL,
    work_id INTEGER NOT NULL,
    is_visible INTEGER NOT NULL CHECK(is_visible IN (0, 1)),
    created_at TEXT NOT NULL,
    updated_at TEXT NOT NULL,
    PRIMARY KEY(user_id, work_id),
    FOREIGN KEY(user_id) REFERENCES users(id) ON DELETE CASCADE,
    FOREIGN KEY(work_id) REFERENCES works(id) ON DELETE CASCADE
);
```

有効な表示値は次の優先順位で決定する。

1. 当該Tailscale利用者の `user_work_visibility.is_visible`
2. 個別行がない場合は `works.is_visible`

概念上は次の式になる。

```sql
COALESCE(user_work_visibility.is_visible, works.is_visible)
```

## migration

schema 8から9への更新時に、既存利用者へ個別visibility行を自動生成しない。

このため1.2.3から1.3.0へ上書き更新した直後は、全利用者が従来の `works.is_visible` を継承し、表示結果は変わらない。

お気に入り、視聴済み、再生位置、履歴、TMDb情報、動画・字幕には変更を加えない。

## Windowsランチャー

「作品の表示設定」へ `対象ユーザー` を追加する。

選択肢:

- 共通設定
- これまでにTailscale経由でアクセスした有効ユーザー

Tailscaleユーザーは初回アクセス時に既存identity処理でDBへ登録されるため、初回アクセス前のユーザーをランチャー側で推測・事前登録しない。

ユーザー選択時の表示:

- `共通表示設定`: `works.is_visible` を編集中
- `個別設定`: そのTailscaleユーザーの個別設定あり
- `共通設定を継承`: 個別設定なし

既存の次のUIは維持する。

- 作品名フィルター
- クリア
- 表示 n / 全m作品
- すべて選択 / すべて解除
- 選択 n / 全m作品

未保存の変更がある状態で対象ユーザーを切り替える場合は、破棄確認を表示する。

## 個別設定の保存

Tailscaleユーザーへ保存した時点で、その時点の登録作品について表示／非表示をスナップショット保存する。

その後追加された新規作品には個別行が存在しないため、共通設定を継承する。

これにより、新規作品を自動的に全ユーザー非表示に固定することを避ける。

## 共通設定に戻す

Tailscaleユーザー選択時に「共通設定に戻す」を利用できる。

実行すると、そのユーザーの `user_work_visibility` を削除する。

以後は全作品で共通設定を継承し、新規作品も同様に共通設定へ追従する。

## ブラウザ側の適用範囲

有効visibilityは次のすべてへ同じように適用する。

- 作品目録・検索
- 作品詳細
- 作品内動画一覧
- 動画詳細
- 動画配信
- 外部字幕
- TMDb poster / backdrop
- TMDb人物画像
- 監督／演出・出演者／声優名鑑
- お気に入り作品・動画
- 続きから見る
- 次に見る
- 最近見た作品
- 視聴履歴
- ライブラリ件数

非表示作品はそのユーザーについて直接URLを指定しても404とする。

## セキュリティ

- ブラウザにvisibility管理APIを追加しない
- 設定変更はWindowsランチャーからSQLiteへ直接反映
- Tailscale identityは既存のServe経路だけを使用
- serverはlocalhost bind限定
- 任意のローカルパスを公開しない
- 非表示化はデータ削除ではない
