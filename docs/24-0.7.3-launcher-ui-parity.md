# 0.7.3 WindowsランチャーUI統一

## 背景

動画版と姉妹アプリ `mp3-source-music-library` のWindowsランチャーを実機で並べて確認したところ、機能は近い一方で、フォント・ウィンドウ幅・余白・入力部品・ボタン配置が微妙に異なっていた。

音楽版mainを基準UIとして、動画版固有の機能を残したままWindowsランチャーの見た目を統一する。

## 共通化した見た目

- 標準フォント: `Yu Gothic UI`
- タイトル: 20pt bold
- 本文: 10pt
- 補助表示: 9pt
- ログ: `Consolas` 9pt
- ウィンドウ: `780x690`
- 最小サイズ: `700x590`
- main padding: 18
- フォルダー指定: LabelFrame + パス表示 + `変更`
- 主ボタン: `ライブラリを開始 / ブラウザで開く / 停止`
- 右側: `データ保存先を開く`
- 外部接続: `外部接続（Tailscale）` LabelFrame
- ステータス: 10pt bold

## 動画版として維持する機能

- メタデータJSONの指定・取込
- 440作品 / 4,869動画のメタデータ状態表示
- ffprobe状態表示
- 起動時スキャン
- MATCHED / MISSING / NEW_FILE / 字幕 / ffprobe進捗
- 現在処理中ファイルと経過時間
- バックアップ
- Tailscale Serve
- Ownerブラウザ認証

UI統一のために動画・字幕ファイル、SQLiteの内容、スキャン判定ロジックは変更しない。

## 回帰テスト

`tests/test_launcher_ui_parity.py` で音楽版基準のUIトークンと主要配置を固定する。

CIでは従来どおりPython 3.11 / 3.13の全テスト、440作品 / 4,869動画fixture、Windowsインストーラー生成を実行する。
