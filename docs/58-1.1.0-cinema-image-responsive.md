# 1.1.0 シネマ蔵書館 画像アセット化＋レスポンシブ強化

## 目的
Run #185 のUIをベースに、ヘッダー・左メニュー・フッターへ独立した装飾SVGを導入し、モックアップにより近い「映画館の一体感」を出す。

## 画像アセット
- `cinema-header.svg`: 赤い幕、木枠、真鍮、照明、中央看板枠
- `cinema-sidebar.svg`: 暗い木製パネル、フィルムリール、映画館外観
- `cinema-footer.svg`: えんじの布地、真鍮ライン、フィルムリール

文字・検索欄・ボタン・メニューラベルは画像へ焼き込まずHTMLで重ねる。これにより、PC・タブレット・スマートフォンで再配置できる。

## レスポンシブ
- PC: 1200px以上。左サイドバー常設、フルヘッダー、フッター装飾。
- Tablet: 768px〜1199px。左サイドバーを収納し、上部の圧縮ナビとメニューボタンを利用。
- Smartphone: 767px以下。ドロワーメニュー、簡略ヘッダー、下部ナビ、作品詳細1カラム。

## 維持する機能
検索、再生、お気に入り、人物リンク、上映中、次回上映、作品目録、再スキャン、診断、TMDb表示など既存機能は変更しない。

## バージョン
表示バージョンは `1.1.0` を維持する。
