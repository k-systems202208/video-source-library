# 自宅動画ライブラリ 1.2.0

## 概要

1.2.0では、関町北映画館に通常表示する作品をOwnerが限定できる「作品表示設定」を追加した。

作品を非表示にしても削除は行わず、動画・TMDb情報・お気に入り・視聴履歴を保持する。

## 主な追加

### 作品表示設定
- 作品単位で「表示中 / 非表示」
- 既存作品・新規取込作品は初期状態で表示
- 作品詳細から単独切替
- 作品目録の表示設定モード
- `表示中 / 非表示 / すべて` の一覧切替
- 複数作品の一括表示／非表示
- 非表示作品の直接URL表示・再生は維持

### 通常画面からの除外
非表示作品は次から除外する。

- 作品目録・検索
- 上映中・次回上映
- お気に入り作品・動画
- 最近見た作品・視聴履歴
- 監督／演出 人物名鑑
- 主な出演者／声優 人物名鑑
- 人物からの作品検索

### DB / API
- application: 1.2.0
- SQLite schema: 8
- `works.is_visible`
- Owner専用 `PUT /api/admin/works/visibility`
- Owner専用 `GET /api/works?visibility=hidden|all`
- metadata再取込でもvisibilityを保持

### PWA
- shell cache: `video-library-shell-v5`

## 継続する主要機能

- TMDb matcher 8
- people sync 9
- people audit 8
- 主な出演者／声優の顔写真
- 監督／演出のテキスト名鑑
- FFmpeg / ffprobe同梱
- 全動画形式の再生経路
- 外部字幕
- Tailscale Serve
- Backup / Restore
- PlaybackCache
- 440作品 / 4,869動画のCI合成データ検証

## 更新方法

1.1.0へ上書きインストール可能。

初回起動時にSQLite schema 7から8へ自動migrationし、既存作品はすべて「表示中」として開始する。

利用者データは `%LOCALAPPDATA%\VideoLibrary` に保持し、上書きインストールで削除しない。
