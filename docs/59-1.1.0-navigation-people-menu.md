# 1.1.0 左メニュー遷移修正・人物名鑑

## 目的
Run #188 で導入した左館内メニューを、表示中のDOMへ単純スクロールする方式から正式なハッシュルーティングへ変更し、作品詳細画面からでも確実に画面遷移できるようにする。

## 左メニュー
- 上映中
- 次回上映
- 作品目録
- 監督／演出
- 主な出演者／声優

診断・再スキャンは左メニューから除外する。診断ページ、再スキャン機能そのものは削除しない。

## 人物名鑑
`/api/people?role=director|cast` を追加し、作品マスターの `director_or_direction` / `main_cast_or_voice_actors` から人物名と登録作品数を集計する。

人物名鑑で人物を選択すると、既存の `#/person/<name>` ルートを利用して、その人物が関わる登録作品一覧を表示する。

## 画面遷移
- `#/home/continue` : 上映中
- `#/home/next` : 次回上映
- `#/library` : 作品目録
- `#/people/directors` : 監督／演出
- `#/people/cast` : 主な出演者／声優
- `#/person/<name>` : 人物別作品一覧
- `#/work/<id>` : 作品詳細

PC / タブレット / スマートフォンで同じルート体系を使用する。

## 維持する機能
再生、TMDb、人物リンク、お気に入り、検索、カテゴリ、並び替え、60件ページング、レスポンシブ映画館UI、表示バージョン1.1.0は変更しない。
