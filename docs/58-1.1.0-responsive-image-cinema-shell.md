# 1.1.0 シネマ蔵書館 画像装飾レスポンシブシェル

Issue #130。Run #185 のデザインを、確認済みモックアップへさらに近づける。

## 方針
- 文字・操作要素はHTMLのまま保持する。
- 赤い幕、木枠、真鍮、照明、映画館外観、フッター布地はSVG画像としてCSSへ埋め込む。
- 追加の外部画像ファイルを必要としないため、PyInstaller/Installerの同梱漏れを防ぐ。

## レスポンシブ
- PC 1200px以上: 左サイドメニュー常設、フルヘッダー、装飾フッター。
- Tablet 768-1199px: サイドメニューをドロワー化。ヘッダーを圧縮。
- Smartphone 767px以下: 1カラム、ドロワー、下部4ボタンナビ、コンパクトヘッダー。

## メニュー
上映中、次回上映、作品目録、俳優・監督検索、診断、再スキャン。既存機能へ接続し、新規DB/APIは追加しない。

## 非変更
再生、TMDb、人物リンク、お気に入り、検索API、DBスキーマ、表示バージョン1.1.0。
