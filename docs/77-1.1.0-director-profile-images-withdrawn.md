# 1.1.0 監督／演出 顔写真機能の撤回

## 方針

監督／演出については顔写真を表示しない。

人物名鑑では、従来どおり監督／演出名と登録作品数を表示し、人物名から該当作品へ移動できる構成を維持する。

主な出演者／声優の顔写真機能は維持する。

## 撤回対象

以下の監督／演出向け機能を通常動作から外す。

- TMDb Director系crewを使った監督人物リンクの自動作成
- 監督プロフィール画像のダウンロード
- /api/people?role=director の profileUrl
- 監督／演出名鑑の顔写真カード
- tmdb-director-audit-*.csv/json
- 監督写真専用のPlaywright fixture / E2E

## DB schema 7

schema 7は既に配布済みのため、schema 6へダウングレードしない。

`tmdb_work_people.role='DIRECTOR'` を保存できる定義は後方互換のため残すが、通常処理では新規に監督写真用リンクを作成しない。

既に作成済みのDIRECTORリンクや共用人物画像についても、DB破壊や画像削除は行わない。UIと通常同期処理から参照しないため、既存ユーザー環境でも安全に無効化される。

## people sync version

人物同期versionは9を維持する。

監督写真対応版を一度実行した環境でversionを巻き戻すと、将来の再同期判定と衝突する可能性があるため、version番号は戻さない。

同期内容は出演者／声優のみへ戻す。

## 維持する機能

- 主な出演者／声優のプロフィール写真
- people audit v8
- 監督／演出の人物名鑑
- 監督／演出名からの作品絞り込み
- DB schema 7
