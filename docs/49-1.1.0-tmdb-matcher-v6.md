# 1.1.0 TMDb matcher v6

## 実機監査

2026-09-16 22:40生成の matcher v5 監査CSVを確認した。

- 440作品
- MATCHED 424
- REVIEW 13
- UNMATCHED 3

v5で `LIAR GAME`、`BLOODY MONDAY`、`アンタッチャブル〜事件記者・鳴海遼子〜`、`妻は、くノ一〜最終章〜` は改善した。

一方、正しいTMDb TVレコードが存在する `TRICK` と `GOOD LUCK!!` は、英字検索だけでは別作品が優先されていた。

## v6修正

- matcher versionを6へ更新。
- search cache namespaceをv3へ更新。
- 実機監査済みの日本語別名を検索・タイトル照合へ追加。
  - `TRICK` ↔ `トリック`
  - `GOOD LUCK!!` ↔ `グッドラック`
- TMDb IDはマッチャーへ固定せず、検索結果から従来のタイトル・年・media contextで選択する。
- v5でMATCHED済みの424件はAPI再検索せず保持する。
- REVIEW / UNMATCHEDだけを再評価する。
- 表示バージョンは1.1.0を維持する。

## 安全策

- 複数作品をまとめたライブラリ項目は従来どおり自動確定しない。
- TMDb候補がない作品や低信頼候補を無理にMATCHEDへ昇格しない。
- 元動画、字幕、再生状態は変更しない。

## 回帰テスト

- `TRICK` から日本語別名検索で2000年TV候補を取得できる。
- `GOOD LUCK!!` から日本語別名検索で2003年TV候補を取得できる。
- 日本語別名と英字タイトルのtitle similarityが1.0になる。
- search cache namespaceがv3になる。
- 既存のv4以降MATCHED保持を維持する。
