# 1.1.0 ポスター表示仕上げ

## 背景

matcher v7実機監査で440作品のTMDb照合を完了し、MATCHED 435件は全件ポスターキャッシュ済みとなった。

## 対応

- 作品一覧カードのポスター表示を仕上げ。
  - hover時の浮き上がりと枠強調
  - ポスター画像の軽いズーム
  - 作品名を2行までに収める
  - 画像取得失敗時は従来どおりタイトルフォールバック
- 「続きから見る」「次に見る」に作品ポスターを追加。
  - APIは既存のローカルTMDbキャッシュURLだけを返す
  - ポスターなし／読込失敗時は作品名先頭文字を表示
- 作品詳細はポスターなし／読込失敗時にも同じサイズのフォールバックを表示し、レイアウトを維持。
- 人物リンク、TMDb matcher、動画・字幕・視聴状態には変更を加えない。
- 表示バージョンは1.1.0を維持。

## テスト

- continue-watching が `posterUrl` を返す
- next-up が `posterUrl` を返す
- UIにホーム用サムネイルとフォールバックが存在する
- 詳細ポスターのフォールバックが存在する
- 既存の監督／出演者リンクを維持する
