# 0.8.0 外部字幕のブラウザ再生

## 目的

0.7.xで完成した外部字幕の検出・安全な動画紐付けを、実際のブラウザ再生へ接続する。

0.8.0では紐付済み字幕が存在する動画を開いた場合、字幕を初期状態からONにする。

## 対象形式

- `.vtt`: UTF-8 WebVTTとして正規化して配信
- `.srt`: 配信時にWebVTTへ変換
- `.ass` / `.ssa`: Events / Dialogueを読み取り、タイムコードとテキストをWebVTTへ変換

元字幕ファイルは一切変更しない。

ASS / SSAの高度な装飾、位置指定、フォント指定等はWebVTT変換では保持せず、字幕本文と改行を優先する。

## 配信API

```text
GET /subtitle/<subtitle_id>.vtt
```

配信条件:

1. `subtitles.id` が存在する
2. `video_id IS NOT NULL`
3. `is_available = 1`
4. 拡張子がSRT / VTT / ASS / SSAのいずれか
5. `relative_path` を動画ルート配下へ解決した実ファイルが存在する
6. `resolve()` 後も動画ルート外へ出ない

実ファイルの絶対パスや元ファイル名はレスポンスへ公開しない。

レスポンスは `Content-Type: text/vtt; charset=utf-8`、`Cache-Control: no-store` とする。

## 字幕の初期選択

動画詳細APIは紐付済み字幕を次の優先順で返す。

1. 明示的な日本語 (`ja` / `jp` / `jpn` / `japanese`)
2. `is_default = 1`
3. forcedではない通常字幕
4. ID順

先頭字幕だけに `preferred: true` を付与する。

ブラウザUIは各字幕を `<track kind="subtitles">` として動画要素へ追加し、`preferred` 字幕を `default` かつ初期 `showing` にする。

字幕が1件でもあれば、最初の再生時点では必ず1件をONにする。字幕が0件なら字幕OFFのままとする。

初期化は一度だけ行う。利用者がネイティブ動画コントロールから字幕OFFまたは別字幕を選択した後は、その再生中にアプリ側から再度強制しない。

## PWA

`/subtitle/*` は `/api/*`、`/video/*` と同様にService Workerキャッシュ対象外とする。

## 変更しないもの

- 元動画
- 元字幕
- 字幕マッチングロジック
- 「対応動画なし」7件の診断分類
- IDX / SUB / SMIの未対応扱い
- 埋込字幕の抽出

## テスト

- UTF-8 / CP932 SRT → WebVTT
- VTTヘッダー正規化
- ASS / SSA Dialogue → WebVTT
- 字幕HTTP配信
- 存在しない字幕IDの404
- `../` またはsymlink等による動画ルート外参照拒否
- 日本語字幕の優先順
- `preferred` が常に1件だけ
- プレーヤーの `<track>` / default ON処理
- Service Worker字幕キャッシュ除外
- Python 3.11 / 3.13全テスト
- 440作品 / 4,869動画fixture
- Windows Installer生成
