# 1.1.0 シネマ蔵書館 詳細画面 第2段階

## 目的
Run #177 のベースデザインを、採用したモックアップAのクラシック映画館・映画パンフレット風の階層へさらに近づける。

## 変更内容
- 詳細ポスターをデスクトップ約205pxへ拡大し、真鍮色の額縁を強化
- タイトルに `FEATURE PRESENTATION` の小見出しを追加し、作品名を主役化
- お気に入りを右端の大きな枠からタイトル情報内の小型ボタンへ移動
- 監督・出演者リンクを丸型チップから銘板風へ変更
- シリーズ切替を「上映プログラム / PROGRAM」として整理
- 各話一覧を「上映目録 / SCREENING LIST」として整理
- 各話タイトルを強調し、解像度・Codec・時間などの技術情報を控えめに表示
- ヘッダーの看板感を強化
- 700px / 440px 以下のレスポンシブ調整を追加

## 変更しないもの
- 再生ロジック
- TMDb照合・画像取得
- 人物リンクの遷移
- お気に入り保存処理
- DBスキーマ
- 表示バージョン `1.1.0`

## テスト

- ポスター・背景・人物リンク・お気に入り・再生フックの維持
