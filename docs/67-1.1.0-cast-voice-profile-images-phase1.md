# 1.1.0 主な出演者／声優 顔写真（第1段階）

## 目的

人物名鑑の「主な出演者／声優」にTMDbのプロフィール画像を表示し、名前だけの一覧より人物を探しやすくする。

## 安全な人物照合

- 既存の `main_cast_or_voice_actors` は正本として残す。
- 人物名をTMDb全体から単独検索して自動確定しない。
- 作品自体がTMDbで `MATCHED` の場合のみ、その作品のクレジットから人物候補を取得する。
- 映画は `/movie/{id}/credits`、TVは `/tv/{id}/aggregate_credits` を利用する。
- ローカル人物名とTMDbの `name` / `original_name` が正規化後に一意一致した場合だけ人物IDを保存する。
- 同名候補が複数ある、または一致しない場合は写真なしのままにする。

## DB schema 6

`tmdb_people` にTMDb人物ID、表示名、プロフィール画像パス等を保存する。

`tmdb_work_people` に作品、ローカル人物名、TMDb人物IDの対応を保存する。第1段階では role は `CAST` のみ。

既存DBは起動時にschema 5から6へ自動更新し、作品・視聴状態等は保持する。

## 画像キャッシュと配信

- 顔写真は `TMDbImages/person/{personId}.*` に保存する。
- サイズは `w185` を使用する。
- WebブラウザからTMDbへ直接アクセスせず、アプリの `/tmdb-person-image/{personId}` から配信する。
- キャッシュファイルが欠けた場合は既存のTMDb画像配信と同様にオンデマンドで自己修復する。
- 外部URL利用時も同じアプリ内URLを使う。

## 初回自動同期

既存ユーザーが追加操作をしなくても顔写真を取得できるよう、TMDbトークンが設定済みで人物同期version 1が未完了の場合、通常の起動スキャンとブラウザ起動後に人物情報だけをバックグラウンド同期する。

- 初回成功後は完了マーカーを保存し、通常起動では繰り返さない。
- 一部失敗した場合は完了扱いにせず、次回起動時に自動再試行する。
- 手動の「TMDb同期」を実行した場合も人物情報・顔写真を更新し、成功時に同じ完了マーカーを保存する。

## UI

- 「主な出演者／声優」は顔写真付きの縦型人物カードで表示する。
- 顔写真がない人物は `PROFILE NOT AVAILABLE` のフォールバックを表示する。
- 監督／演出は第1段階では従来の文字カードのまま。
- 人物カードをクリックした後の「その人物が関わる登録作品」への導線は従来どおり。
- PC / Tablet / Smartphone でレスポンシブ表示する。

## テスト

- TMDb movie credits / TV aggregate credits endpoint。
- 一意な人物名だけが自動照合されること。
- 同名候補が複数の場合は自動照合しないこと。
- credits APIレスポンスのキャッシュ。
- 人物画像ローカルキャッシュ。
- `/tmdb-person-image/{id}` 配信。
- schema 5 → 6 移行。
- 初回自動人物同期マーカー。
- Service Workerが人物画像を静的shellキャッシュしないこと。
- Playwrightで顔写真、写真なしフォールバック、人物カードクリックをPC / Tablet / Smartphoneで実操作確認。
