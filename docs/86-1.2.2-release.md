# 自宅動画ライブラリ 1.2.2

## 概要

1.2.2では、Windowsランチャーの「作品の表示設定」に作品名の部分一致フィルターを追加した。

約440作品の一覧から、表示対象を変更したい作品を素早く探せる。

## 追加

- `作品名フィルター` テキストボックス
- 入力中の即時絞り込み
- 大文字小文字を区別しない部分一致
- Unicode NFKC正規化
- 前後空白を無視
- `クリア` ボタン
- `表示 n / 全m作品` 件数表示

## チェック状態

フィルターは表示だけを変更する。

絞り込みによって画面から隠れた作品のチェック状態は保持し、フィルター解除後に同じ状態で再表示する。

`すべて選択 / すべて解除` は従来どおり全作品へ適用する。

## 継続仕様

- application: 1.2.2
- SQLite schema: 8
- PWA shell: v6
- 表示対象管理はWindowsランチャーのみ
- ブラウザにvisibility管理UI/APIは持たない
- 非表示作品は直接URLを含めブラウザから取得不可
- metadata再取込でも `is_visible` を保持

## 更新方法

1.2.1へ上書きインストール可能。

schemaは8のままなので追加migrationはない。既存の表示／非表示設定はそのまま引き継ぐ。
