# 自宅動画ライブラリ 1.2.1

## 概要

1.2.0でブラウザへ追加した作品表示設定を見直し、1.2.1では表示対象の管理をWindowsランチャーへ移動した。

ブラウザは閲覧・再生専用とし、表示対象の変更はWindowsランチャーからのみ行う。

## Windowsランチャー

- `表示設定` ボタンを追加
- 登録済み全作品をチェックリスト表示
- 現在の表示状態をチェックへ反映
- `すべて選択 / すべて解除` チェックボックス
- 選択作品数を表示
- 保存時にチェックされた作品だけをブラウザ表示対象へ設定
- 約440作品をスクロールして操作可能

## ブラウザ

1.2.0の表示管理UIを撤去。

- 表示設定モードなし
- 表示中 / 非表示 / すべて切替なし
- 一括表示 / 非表示なし
- 作品詳細の表示切替なし

visibility管理Web APIも撤去した。

非表示作品は直接URLを含めてブラウザから取得できない。

## DB

- application: 1.2.1
- SQLite schema: 8
- `works.is_visible` を継続利用
- metadata再取込でも表示状態を保持

## PWA

- shell cache: `video-library-shell-v6`

## CI

Windows RunnerでChocolateyが一時的に504を返す場合へ備え、FFmpeg / Inno Setup導入を最大3回リトライする。

## 更新方法

1.2.0へ上書きインストール可能。

schemaは8のままなので追加migrationはない。1.2.0で設定済みの `is_visible` はそのままランチャーの初期チェック状態として引き継ぐ。
